# 마이

## Background

수강생이 남긴 추가요와 앵콜의 결과는 지금 그 곡이나 클래스 상세에 다시 들어가야만 보인다. 알림(F-20)이 없어서, 추가요한 곡의 클래스가 열렸는지, 앵콜이 강사에게 전달됐는지를 알 방법이 사실상 없다. 요청을 남긴 사람이 결과를 모르면 다시 요청할 이유도 사라진다.

로그아웃하는 곳도 없다. 한 번 로그인하면 같은 기기에서 다른 계정으로 바꾸거나 기록을 남기지 않고 나갈 수 없다.

마이는 알림이 없는 지금, 내가 남긴 요청이 어떻게 됐는지 확인하는 유일한 곳이다(와이어프레임 U-09).

## Goal

수강생이 내가 남긴 추가요와 앵콜이 지금 어떻게 됐는지 한곳에서 보고, 열린 클래스로 바로 가게 한다.

## How it works

### 들어가기

- 홈 위쪽에서 마이로 들어간다. 하단 탭바는 아직 없다.
- 로그인하지 않았으면 무엇을 할 수 있는지 먼저 말하고, 카카오로 시작할 수 있다. 로그인하면 마이로 돌아온다. 둘러보기는 로그인 없이 된다는 것도 알려준다.

### 내 추가요

- 내가 남긴 추가요를 모두 본다. 취소한 것은 보이지 않는다.
- 클래스가 열린 추가요는 눈에 띄게 맨 위에 둔다. 누르면 열린 클래스로 간다.
- 기다리는 중인 추가요는 곡, 아티스트, 내가 고른 권역, 남긴 날짜와 지금 이 곡을 기다리는 사람 수를 보여준다. 누르면 곡 상세로 가고, 수정·취소는 거기서 한다.

### 내 앵콜

- 내가 앵콜한 클래스를 모두 본다. 취소한 것은 보이지 않는다.
- 클래스, 강사, 날짜와 진행 상태를 보여준다: 모으는 중(지금 인원/기준), 전달됨, 검토 중, 앵콜 클래스가 열렸어요, 이번엔 어려워요, 앵콜 기간 끝남. 상태 문구는 클래스 상세와 같다.
- 앵콜 클래스가 열린 것은 맨 위에 두고, 누르면 앵콜 클래스로 간다. 나머지는 누르면 원 클래스 상세로 가고, 수정·취소는 거기서 한다.

### 내 정보

- 카카오 닉네임을 보여준다. 이번에는 바꿀 수 없다.
- 로그아웃할 수 있다. 로그아웃하면 홈으로 간다.

### 이번에 하지 않는 것

- 회원 탈퇴 (F-09). 로그인 계정 자체를 지우려면 서버 전용 관리자 키와 카카오 연결 끊기가 필요하고, 남기는 기록의 범위도 정해야 한다. 출시 전에 따로 한다
- 약관 보기·문의하기 (약관 동의 U-08과 함께)
- 강사 신청·내 클래스 관리 (F-11, F-12). 아직 없는 기능의 입구는 두지 않는다(원칙 6)
- 알림 설정 (F-20), 닉네임 바꾸기, 하단 탭바
