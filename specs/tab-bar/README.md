# 하단 탭바

## Background

홈·클래스 목록·추가요 랭킹·마이가 다 생겼지만, 서로 오가는 길은 홈 머리의 "마이" 버튼과 섹션별 더보기뿐이다. 랭킹에서 마이로, 목록에서 홈으로 가려면 로고를 눌러 홈을 거쳐야 한다. 04 IA는 처음부터 네 화면을 하단 탭으로 묶기로 했고, 그 화면들이 모두 생길 때까지 미뤄 두었다. 디자인 시안(round-3)의 "탭바 알약" 움직임도 탭바가 생겨야 붙는다.

## Goal

수강생 화면 어디서든 홈·찾기·추가요·마이 네 곳으로 한 번에 간다.

## How it works

### 탭으로 오가기

- 홈, 클래스 목록, 추가요 랭킹, 마이 네 화면의 아래에 탭바가 있다. 로그인 없이 누구나 쓴다.
- 홈 탭은 홈으로, 찾기 탭은 검색으로(검색 칸에 바로 커서가 간다), 추가요 탭은 추가요 랭킹으로, 마이 탭은 마이로 간다. 마이는 비로그인이면 지금처럼 로그인 안내가 보인다.
- 지금 있는 화면의 탭이 켜져 있다. 클래스 목록에 있으면 찾기 탭이 켜진다.
- 탭을 누르면 켜진 표시가 그 탭으로 옮겨 가고 아이콘이 살짝 뛴다. 동작 줄이기를 켠 사용자에게는 움직임 없이 바로 바뀐다.
- 탭바는 화면 맨 아래에 고정돼 내용이 길어도 가려지지 않고, 화면 내용의 끝이 탭바에 가려지지 않는다.

### 탭바가 없는 화면

- 곡 상세, 클래스 상세, 검색(입력 중), 약관 동의, 약관 문서, 운영 화면에는 탭바가 없다. 상세·입력 화면은 로고나 뒤로 가기로 나간다.
- 홈 머리의 "마이" 버튼은 탭바가 대신하므로 없앤다.

### 이번에 하지 않는 것

- 탭에 숫자 표시(알림 F-20과 함께)
- 강사용 탭 (04 IA: 강사 메뉴는 탭을 따로 두지 않는다)
- 당겨서 새로고침 (design.md 보류)
