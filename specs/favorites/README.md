# 찜

## Background

클래스 목록·곡 상세·강사 프로필에서 마음에 드는 클래스를 봐도 다시 찾으려면 같은 길을 되짚어야 한다. 예약은 강사의 외부 링크로 넘어가 끝나므로, 올빗 안에는 "내가 눈여겨본 클래스"가 남지 않는다. 마이에는 내 추가요·앵콜만 있다(F-10). 찜이 있으면 고민 중인 클래스를 모아 두고, 마감되거나 취소된 것도 바로 알 수 있다(F-22).

## Goal

로그인한 수강생이 클래스를 찜해 두고 마이에서 한 번에 보며, 찜한 클래스가 마감·취소됐는지 바로 안다.

## How it works

### 찜하기 (수강생)

- 클래스 상세에서 찜 버튼을 누르면 찜이 되고, 다시 누르면 빠진다. 어떤 상태의 클래스든 찜할 수 있다(마감된 것도 앵콜을 기다리며 둘 수 있다).
- 로그인하지 않았으면 로그인 시트가 열리고, 로그인한 뒤 같은 화면으로 돌아와 그 클래스가 찜된다(추가요·앵콜과 같은 흐름). 약관 동의 전이면 동의 화면으로 간다.
- 찜은 나만 본다. 몇 명이 찜했는지는 보여주지 않는다.

### 찜 목록 (수강생)

- 마이에 찜한 클래스가 보인다. 다가오는 클래스가 날짜 순으로 먼저, 지난·취소된 클래스가 뒤에 온다.
- 마감·끝남·취소된 클래스에는 그렇다고 표시된다. 누르면 클래스 상세로 가서 앵콜하거나 같은 곡 다른 클래스를 찾을 수 있다.
- 숨겨졌거나 강사가 비공개가 된 클래스는 목록에 나오지 않는다.

### 이번에 하지 않는 것

- 찜 수 표시, 찜 많은 순 정렬
- 곡·강사 찜
- 마이 밖(목록·티켓)에서 바로 찜하기
- 찜한 클래스 마감 임박 알림(F-20)
