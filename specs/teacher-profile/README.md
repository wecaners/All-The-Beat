# 강사 프로필 페이지

## Background

지금 강사 정보는 클래스 상세 안에만 있다. 수강생이 마음에 드는 강사를 찾아도 그 강사의 다른 클래스를 모아 볼 곳이 없고, 강사 카드에서 갈 수 있는 곳은 인스타그램뿐이다. 강사 쪽에서도 올빗에 클래스를 올려 두고 "내 클래스는 여기서 보세요"라고 걸 링크가 없다. 클래스마다 주소가 따로라, 클래스가 끝나면 링크도 쓸모가 없어진다.

강사가 직접 클래스를 올리고(F-12) 대리 등록 프로필을 가져올 수 있게 된(F-19) 지금, 강사가 인스타 프로필에 계속 걸어 둘 수 있는 주소 하나가 있어야 올빗으로 사람이 들어온다.

## Goal

누구나 강사 한 명의 소개와 그 강사의 다가오는 클래스, 가르쳐 온 곡을 한 페이지에서 보고, 강사는 그 주소를 인스타에 걸어 둔다.

## How it works

### 강사 프로필 보기 (누구나)

- 주소는 강사의 인스타 아이디로 정해진다(예: `/teacher/minji.dance`). 로그인 없이 볼 수 있다.
- 맨 위에 강사 이름, 인스타 아이디, 주로 활동하는 지역, 사진·한 줄 소개가 보이고 인스타그램으로 가는 길이 있다. 포트폴리오 영상이 있으면 보여준다.
- 사진·소개·영상은 클래스 상세와 같은 규칙을 따른다. 넣은 것만 보이고, 운영자가 대신 등록한 강사는 게재에 동의한 경우에만 보인다.
- 다가오는 클래스가 날짜 순으로 보이고, 누르면 클래스 상세로 간다. 마감된 클래스도 보여서 앵콜하러 갈 수 있다.
- 지난 클래스는 그 강사가 가르쳐 온 곡 목록으로 보여준다. 곡을 누르면 곡 상세로 간다(곡이 주인공).
- 다가오는 클래스가 없으면 그렇다고 말하고, 가르쳐 온 곡에서 추가요하러 갈 수 있게 한다.

### 어디서 들어오나

- 클래스 상세의 강사 카드에서 "강사 프로필 보기"로 들어온다. 인스타그램 버튼은 그대로 둔다.
- 강사는 이 주소를 복사해 인스타 프로필이나 스토리에 건다. 링크를 공유하면 강사 이름이 미리보기 제목으로 보인다.

### 보이지 않는 강사

- 승인되지 않았거나 정지된 강사, 게재 동의 전인 대리 등록 강사, 탈퇴한 강사의 주소는 없는 페이지로 보인다.
- 숨긴 클래스와 취소된 클래스는 목록에 나오지 않는다.

### 이번에 하지 않는 것

- 강사가 자기 사진·소개·영상을 직접 고치는 화면(지금처럼 운영자가 넣는다)
- 강사 검색, 강사 목록, 강사 팔로우
- 공유용 이미지(F-23), 별도 짧은 주소
- 인스타 아이디가 바뀌었을 때 옛 주소를 새 주소로 넘겨주기
