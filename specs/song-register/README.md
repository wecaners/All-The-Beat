# 수강생 신규 곡 등록

## Background

검색해서 곡이 없으면 지금은 "아직 올빗에 없는 곡이에요"에서 끝난다. 추가요는 올빗의 핵심 무기인데, 정작 올빗이 모르는 곡은 추가요할 수가 없다. 유행하는 신곡일수록 아직 DB에 없을 가능성이 크고, 그 곡을 처음 찾는 사람이 바로 올빗이 필요한 사람이다. F-02 수용 기준 "결과 없음에서 두 번 안에 추가요"는 수강생이 곡을 만들 수 있어야 지켜진다(F-13).

운영자 클래스 등록에는 이미 "찾는 곡이 없으면 그 자리에서 만들기"가 있다. 같은 규칙을 수강생 검색에도 연다.

## Goal

검색해서 없는 곡을 그 자리에서 곡명·아티스트로 만들고, 바로 그 곡에 추가요한다.

## How it works

### 없는 곡 만들기

- 검색 결과가 없으면 "이 곡 추가요!"로 바로 이어진다. 곡 이름은 검색어로 미리 채워져 있고, 아티스트를 쓴다.
- 아티스트를 치면 이미 있는 아티스트가 보여 고를 수 있다. 다른 표기로 써도 같은 아티스트로 묶인다.
- 같은 아티스트에 같은 이름의 곡이 이미 있으면 새로 만들지 않고 그 곡으로 간다.
- 로그인이 필요하다. 추가요와 같은 로그인·약관 동의 흐름을 거치고, 끝나면 하던 자리로 돌아온다.
- 만든 곡은 바로 쓸 수 있다. 곡 상세로 가면서 추가요 시트가 열려 있어, 희망 권역을 고르고 추가요하면 그 곡의 첫 번째 추가요가 된다.
- 만든 곡은 운영자 곡 목록에 검수 대기로 보인다. 중복이면 운영자가 기존 곡으로 병합하고(F-16), 대표 영상도 운영자가 정한다. 영상이 정해지기 전에는 기본 이미지가 보인다.

### 결과 없음 화면

- "아직 올빗에 없는 곡이에요" 아래에 바로 곡을 만들어 추가요하는 길이 있다.
- 이번 주 핫한 곡이 있으면 "이런 곡은 어때요?"로 두세 곡을 보여준다. 원하는 곡이 없어도 둘러볼 거리가 있다.

### 이번에 하지 않는 것

- YouTube 영상 링크 입력 (대표 영상은 운영자가 검수 때 정한다, F-16)
- 운영자 검수 화면(검수 대기 필터·병합·승인)은 F-16과 함께. 이번에는 곡 목록에 검수 대기 표시만
- 오타 교정 제안("혹시 NEON?") — 별칭 검색으로 대신한다
- 곡 정보 외부 API 자동 검색 (2026-10-26 결정)
