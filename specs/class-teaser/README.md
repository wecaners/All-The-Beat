# 강사 티저 영상

## Background

클래스 상세 맨 위에는 지금 대표 곡의 공식 안무 영상이 보인다. 곡이 무엇인지는 알 수 있지만, 이 강사가 어떻게 가르치는지는 알 수 없다. 강사는 보통 인스타·유튜브에 자기 수업 영상이나 쇼츠를 올려 두고 있는데, 올빗 클래스에는 그 영상을 붙일 자리가 없다. 수강생이 "이 강사는 이렇게 가르쳐요"를 한 번에 보면 예약 링크로 넘어갈 이유가 하나 더 생긴다(F-25).

## Goal

강사(또는 대신 등록하는 운영자)가 클래스에 YouTube 영상 링크 하나를 붙이면, 클래스 상세 맨 위에 그 영상이 보인다.

## How it works

### 티저 영상 넣기 (강사·운영자)

- 클래스 등록·수정에 "티저 영상 링크"를 선택으로 넣는다. YouTube 일반 영상과 쇼츠 링크를 받는다. 비워도 된다.
- 저장할 때 링크에서 영상을 찾고, 다른 곳에 퍼갈 수 있는 영상인지 확인한다. 퍼가기가 막혔거나, 비공개·삭제된 영상이거나, YouTube 링크가 아니면 저장되지 않고 이유를 알려준다(곡 대표 영상과 같은 규칙, F-16).
- 수정에서 링크를 지우면 영상이 빠진다. 클래스를 복사하거나 앵콜 클래스를 만들 때는 원래 클래스의 티저가 따라온다.

### 클래스 상세에서 보기 (누구나)

- 티저가 있으면 클래스 상세 맨 위에 그 영상이 보인다. 지금 그 자리에 있던 대표 곡 안무 영상은 빠진다. 곡 영상은 곡 이름을 눌러 곡 상세에서 볼 수 있다.
- 영상은 YouTube 공식 임베드로, 누르기 전에는 썸네일만 보이고 출처가 표시된다.
- 티저가 없으면 지금처럼 대표 곡 영상이 보인다.

### 이번에 하지 않는 것

- 저장한 영상 정보의 30일 자동 갱신과 "영상 교체 필요" 표시(곡 대표 영상도 아직 하지 않는다)
- 인스타그램 릴스 링크(임베드 정책이 달라 MVP 이후)
- 티저 영상 여러 개, 영상 업로드
