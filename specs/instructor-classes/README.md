# 강사 클래스 등록과 내 클래스

## Background

강사 신청·승인(F-11·F-14)까지 만들었지만, 승인된 강사는 "승인됐어요"에서 멈춘다. 클래스는 여전히 운영자가 대리 등록해야 한다. 올빗의 핵심 가설은 "강사가 추가요를 보고 직접 클래스를 연다"(플로우 5)인데, 강사가 직접 올리는 화면이 없으면 검증할 수 없다. 인스타 스토리에 올리는 것보다 빠르게, 1분 안에 등록하는 게 목표다(F-12).

강사는 같은 장소·가격·링크로 반복해서 연다. 매번 다 쓰게 하면 안 쓴다. 그리고 예약은 외부에서 받으니 마감은 강사가 직접 눌러야 한다.

## Goal

승인된 강사가 1분 안에 클래스를 올리고, 내 클래스에서 상태를 바꾸고, 앵콜에 답하고, 지난 클래스를 복사해 다시 연다.

## How it works

### 내 클래스 (강사)

- 마이의 "강사로 승인됐어요"에서 내 클래스로 들어간다. 승인된 강사만 들어갈 수 있고, 아니면 신청 상태 화면으로 간다.
- 다가오는 클래스와 지난 클래스를 나눠 본다. 클래스마다 날짜·시간·권역·가격·난이도·상태와 예약 링크 클릭 수, 앵콜 수가 보인다.
- 앵콜 기준을 넘어 답이 필요한 클래스가 있으면 맨 위에 보인다. 거기서 "검토할게요" 또는 "이번엔 어려워요"로 답하고, 검토하기로 했으면 그 클래스로 앵콜 클래스를 바로 연다(원 클래스 값이 채워진다).
- 다가오는 클래스에서 마감 임박 표시, 마감하기, 마감 풀기(앵콜이 시작되지 않은 경우만), 취소(사유: 인원 미달·개인 사정·기타)를 할 수 있다. 종료는 시간이 지나면 저절로 된다.
- 지난 클래스는 고칠 수 없고 "복사해서 다시 열기"만 된다.

### 클래스 등록 (강사)

- 한 화면에서 곡(1~3개, 검색해서 고르고 없으면 그 자리에서 만든다), 날짜(달력), 시작·종료 시간(30분 단위), 장소, 가격, 난이도, 예약 링크를 넣는다. 클래스 이름·정원·설명은 선택이다.
- 장소는 내 스튜디오 중에서 고르고(가장 최근 것이 미리 골라져 있다), 없으면 그 자리에서 검색해 추가한다. 권역은 장소에서 자동으로 정해지고 바꿀 수 있다. 예약 링크는 주소를 보고 유형(네이버 예약·오픈채팅·인스타 DM·구글 폼)을 알아서 정한다.
- 곡 상세의 "이 곡으로 클래스 열기"로 들어오면 곡이 미리 골라져 있고, 기다리는 사람 수가 위에 보인다.
- 내 클래스의 "복사해서 다시 열기"로 들어오면 장소·가격·링크·설명이 채워져 있어 날짜와 곡만 바꾸면 된다.
- 저장하면 바로 공개되고(승인된 강사는 검수 없음) 그 클래스 상세로 간다.
- 과거 날짜, 시작보다 이른 종료, http(s)가 아닌 예약 링크, 필수 누락은 저장되지 않고 무엇이 문제인지 안내한다.

### 클래스 수정 (강사)

- 종료 전 클래스는 같은 화면에서 고친다. 일시나 장소를 바꾸면 클래스 상세에 24시간 동안 "변경됨"이 보인다.
- 내 클래스만 고칠 수 있다.

### 이번에 하지 않는 것

- 썸네일·티저 영상(F-25), 스토리 공유 이미지(F-23)
- 조회 수(세는 기능이 없다), 시작 전 "마감됐나요?" 확인 배너
- 스튜디오 사진·시설 편집(운영자 화면 그대로. 강사는 장소 고르기·추가만)
- 랭킹 행의 "이 곡으로 클래스 열기"와 분포 펼치기(곡 상세 입구로 대신한다)
