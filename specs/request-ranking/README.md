# 추가요 랭킹

## Background

추가요는 올빗의 핵심 무기다. 그런데 지금 추가요가 모이는 모습은 홈의 TOP 5와 곡 상세의 숫자로만 보인다. 수강생은 "다른 사람도 이 곡을 기다리는구나"를 다섯 곡 너머로 볼 수 없고, 강사는 어느 곡을 열면 사람이 올지, 어느 동네에서 기다리는지 알 길이 없다.

추가요 랭킹은 수강생에게는 같이 기다리는 재미이고, 강사에게는 "이 곡 열면 사람 온다"는 수요 판이다(F-08). 랭킹에 있는 곡을 보고 강사가 클래스를 열고, 수강생이 추가요를 더하는 순환이 여기서 시작된다.

## Goal

최근 30일 동안 사람들이 가장 기다린 곡을 권역별로도 보고, 거기서 바로 추가요하거나 열린 클래스로 가게 한다.

## How it works

### 랭킹 보기

- 홈 추가요 TOP 5의 더보기로 들어간다. 로그인 없이 누구나 본다.
- 최근 30일 동안 취소되지 않은 추가요가 많은 곡 순으로 최대 50곡을 보여준다. 추가요가 3명 미만인 곡은 나오지 않는다.
- 각 곡에는 순위, 안무 영상 썸네일, 곡명·아티스트, 기다리는 사람 수, 이번 주에 늘어난 수가 보인다.
- 순위 옆에 지난주와 견준 변화(올랐는지, 내렸는지, 새로 들어왔는지)가 보인다.
- 열린 클래스가 있으면 "클래스 N개 열림", 없으면 "아직 클래스 없음"이 보인다. 곡을 누르면 곡 상세로 간다.
- 누가 요청했는지는 보이지 않는다. 숫자로만 보여준다.

### 권역별로 보기

- 전체와 권역별을 오갈 수 있다. 권역을 고르면 그 권역을 희망한 추가요만 다시 센다.
- 고른 권역은 주소에 남아 새로 고침하거나 공유해도 같은 랭킹이 보인다.

### 여기서 추가요하기

- 각 곡에서 바로 "나도 추가요!"를 누를 수 있다. 곡 상세의 추가요와 같은 흐름(로그인·약관 동의·시트)을 그대로 쓴다.
- 랭킹에 없는 곡은 맨 위의 검색 입구에서 찾아 추가요한다.

### 이번에 하지 않는 것

- 강사로 로그인했을 때의 "이 곡으로 클래스 열기"와 권역·시간대·한마디 펼치기 (강사 화면 F-11·F-12와 함께)
- 하단 탭바 (탭바를 만들 때 추가요 탭이 이 화면이 된다)
- 당겨서 새로고침과 순위가 바뀌는 움직임 (design.md 인터랙션 표에서 보류)
