# 운영자 곡 검수와 병합

## Background

곡은 이제 운영자만 만들지 않는다. 수강생이 검색 결과 없음에서 만들고(F-13), 강사가 클래스를 올리며 만든다(F-12). 표기가 다른 같은 곡("NEON"과 "네온", "A2O LITE"와 "에이투오")이 쌓이면 추가요와 클래스가 갈라져서 랭킹도, 곡 상세의 기다리는 수도 반 토막이 난다. 올빗의 핵심인 "곡 하나에 수요를 모으기"가 깨진다.

운영 곡 목록에 "검수 대기" 표시는 붙였지만, 운영자가 할 수 있는 건 곡 정보 수정뿐이다. 검수를 끝내는 버튼도, 중복을 하나로 합치는 길도 없다(F-16).

## Goal

운영자가 검수 대기 곡을 모아 보고, 맞으면 확인하고, 중복이면 기존 곡으로 합쳐서 클래스·추가요·별칭이 한 곡에 모이게 한다. 아티스트도 같은 방식으로 합친다.

## How it works

### 검수 대기 보기·확인 (운영자)

- 운영 곡 목록에서 검수 대기만 모아 볼 수 있고, 누가 만들었는지(수강생·강사·운영자)와 만든 날이 보인다.
- 곡 상세에서 확인하면 검수가 끝난 곡이 된다. 곡명·아티스트·별칭·발매일·대표 영상은 지금처럼 거기서 고친다.

### 곡 병합 (운영자)

- 곡 상세에서 "이 곡을 다른 곡으로 합치기"를 고른다. 합칠 대상은 검색해서 고르고, 자기 자신이나 이미 합쳐진 곡은 고를 수 없다.
- 합치면 이 곡의 클래스·추가요·별칭이 대상 곡으로 옮겨진다. 같은 사람이 두 곡 모두에 추가요했으면 대상 곡 것을 남긴다. 같은 별칭이 이미 있으면 건너뛴다. 이 곡의 이름도 대상 곡의 별칭이 되어 검색에 계속 걸린다.
- 합쳐진 곡의 예전 주소로 들어오면 대상 곡으로 간다(지금도 그렇다). 홈·검색·랭킹·운영 목록에는 더 이상 나오지 않는다.
- 합치기는 되돌릴 수 없다. 누르기 전에 한 번 더 묻고, 옮겨질 클래스·추가요 수를 보여준다.

### 아티스트 수정·병합 (운영자)

- 아티스트 목록에서 대표 이름을 고치고, 중복 아티스트를 다른 아티스트로 합친다.
- 합치면 그 아티스트의 곡·별칭이 대상 아티스트로 옮겨진다. 이 아티스트의 이름도 대상의 별칭이 된다.

### 이번에 하지 않는 것

- 대표 영상 30일 자동 갱신·"영상 교체 필요" 표시(배치가 필요하다)
- 곡 병합 되돌리기
- 수강생·강사 화면 변경(이미 합쳐진 곡은 숨겨지고 주소는 넘어간다)
