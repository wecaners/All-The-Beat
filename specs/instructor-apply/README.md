# 강사 신청과 승인

## Background

지금 올빗의 클래스는 전부 운영자가 대리 등록한다. 강사가 스스로 올빗에 들어올 길이 없어서, 공급이 운영자 손에만 달려 있다. 강사가 직접 클래스를 올리려면(F-12) 먼저 "이 사람이 그 강사가 맞다"를 확인하고 강사 권한을 줘야 한다(F-11·F-14). 인스타그램 계정이 곧 강사의 신원이라, 그 계정으로 본인 확인을 한다.

## Goal

수강생이 마이에서 강사를 신청하고, 인스타 DM으로 받은 코드로 본인을 확인하면, 운영자가 승인해 강사가 된다.

## How it works

### 신청하기 (강사)

- 마이에서 강사 신청으로 들어간다. 로그인이 필요하다.
- 활동명, 인스타그램 계정, 주로 활동하는 지역(여러 개)을 쓰고, 한 줄 소개는 선택이다. 맨 위에 "예약은 지금 쓰는 그대로, 올빗은 보여주는 역할만"을 먼저 말한다.
- 신청하면 승인 대기가 되고, 지금 어느 단계인지(신청 완료 → 인스타 본인 확인 → 운영자 승인)가 보인다.
- 이미 올빗에 있는 인스타 계정이면 신청할 수 없다. 운영자가 대신 등록해 둔 계정이면 그렇다고 알린다(내 계정으로 가져오기는 F-19와 함께).
- 이미 강사면 신청 화면 대신 지금 상태가 보인다.

### 본인 확인 (강사·운영자)

- 운영자가 승인 대기 강사에게 6자리 코드를 발급하고, 그 강사의 인스타 계정으로 DM을 보낸다(운영자가 손으로).
- 강사는 마이의 신청 상태에서 코드를 넣는다. 맞으면 "확인됨"이 되고, 틀리거나 24시간이 지났으면 그렇다고 알린다. 코드는 운영자가 다시 발급할 수 있다.
- 얼마나 걸리는지는 약속하지 않는다. 운영자가 보낼 때 온다.

### 승인·반려 (운영자)

- 운영 화면에서 승인 대기 강사가 활동명·인스타(링크)·권역·신청일·확인 여부와 함께 보인다.
- 승인하면 강사 권한이 생기고 마이에 승인됐다고 보인다. 클래스를 직접 올리는 화면(F-12)이 생기기 전까지는 거기서 끝이다.
- 반려하면 사유를 적는다. 강사는 마이에서 사유를 보고 내용을 고쳐 다시 신청할 수 있다.

### 이번에 하지 않는 것

- 강사가 직접 클래스를 올리는 화면(F-12·T-02·T-03)
- 대리 프로필을 내 계정으로 가져오기(F-19 클레임)
- 인증 코드 DM 자동 발송, 신청·승인 알림(F-20)
- 프로필 사진 올리기(카카오 프로필을 그대로 쓴다)
