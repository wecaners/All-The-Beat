# Feature Specification: 클래스 목록·필터

## Overview

열린 클래스를 가까운 날짜순으로 보고, 검색어·날짜·권역·난이도로 좁혀서 클래스 상세로 간다. 조건은 주소에 남아 공유할 수 있다. 로그인 없이 누구나 본다(F-03, U-03).

## User Scenarios & Testing (mandatory)

### User Story 1: 수강생이 갈 수 있는 클래스를 날짜로 훑는다

- As: 수강생은
- I: 열린 클래스를 날짜순으로 볼 수 있다
- So: 언제 갈 수 있는지 한눈에 보기 위해

#### Acceptance Scenarios

Scenario 1: **들어가기**

- Given: 홈에 다가오는 클래스가 있을 때
- When: 전체 보기를 누르면
- Then: 조건 없는 클래스 목록으로 간다

Scenario 2: **기본 목록**

- Given: 모집중·마감 임박·마감·종료·취소·숨김·미승인 강사의 클래스가 섞여 있을 때
- When: 목록을 열면
- Then: 공개된 모집중·마감 임박 클래스 중 아직 시작하지 않은 것만, 가까운 날짜순으로, 날짜별로 묶여 보인다. 각 항목에 곡명·아티스트, 날짜, 시간, 권역, 강사, 가격, 난이도, 마감 임박 표시가 보인다

Scenario 3: **이어 보기**

- Given: 조건에 맞는 클래스가 20개를 넘을 때
- When: 끝까지 내리면
- Then: 다음 20개가 같은 순서로 이어 붙고, 같은 날짜면 같은 묶음에 들어간다. 더 없으면 멈춘다

Scenario 4: **클래스로**

- Given: 목록이 보일 때
- When: 항목을 누르면
- Then: 그 클래스 상세로 간다

### User Story 2: 조건으로 좁힌다

- As: 수강생은
- I: 날짜·권역·난이도·검색어로 목록을 좁힐 수 있다
- So: 내가 갈 수 있는 클래스만 보기 위해

#### Acceptance Scenarios

Scenario 5: **날짜**

- Given: 목록을 볼 때
- When: 오늘·이번 주·이번 주말 중 하나를 고르거나 날짜를 직접 고르면
- Then: 그 기간(한국 시간)에 시작하는 클래스만 보인다. 다시 누르면 전체로 돌아간다

Scenario 6: **권역 여러 개**

- Given: 목록을 볼 때
- When: 권역을 하나씩 누르면
- Then: 고른 권역들이 모두 켜지고 그 권역의 클래스만 보인다. 켜진 권역을 다시 누르면 꺼진다

Scenario 7: **난이도**

- Given: 목록을 볼 때
- When: 난이도 하나를 고르면
- Then: 그 난이도만 보인다. 다시 누르면 전체로 돌아간다

Scenario 8: **검색어**

- Given: 검색 화면에서 곡이나 아티스트를 치고
- When: 엔터를 치면
- Then: 그 검색어가 적힌 목록으로 와서, 별칭까지 맞는 곡의 클래스만 보인다. 검색어를 지우면 전체 목록이다

Scenario 9: **마감 포함**

- Given: 마감된 클래스가 있을 때
- When: 마감 포함을 켜면
- Then: 마감된 클래스가 흐리게 섞여 보이고, 앵콜이 모이고 있으면 그 수가 보인다. 누르면 클래스 상세로 간다

Scenario 10: **주소 공유**

- Given: 조건을 골랐을 때
- When: 새로 고치거나 주소를 열면
- Then: 같은 조건·같은 결과가 보인다. 모르는 값은 무시된다

### User Story 3: 결과가 없을 때 다음 길을 찾는다

- As: 수강생은
- I: 조건에 맞는 클래스가 없을 때 무엇을 할지 알 수 있다
- So: 막히지 않기 위해

#### Acceptance Scenarios

Scenario 11: **조건 줄이기**

- Given: 조건 조합에 맞는 클래스가 없을 때
- When: 목록을 보면
- Then: 조건을 줄여 보라는 안내와 조건 초기화가 보인다. 초기화하면 검색어만 남고 나머지 조건이 풀린다

Scenario 12: **곡은 있는데 클래스가 없을 때**

- Given: 검색어에 맞는 곡은 있지만 클래스가 없을 때
- When: 목록을 보면
- Then: 그 곡 상세로 가서 추가요할 수 있는 길이 보인다

## Functional Requirements (mandatory)

- FR-1: MUST 홈 다가오는 클래스에 목록으로 가는 입구를 두고, 검색 칸의 엔터는 검색어를 담아 목록으로 보낸다
- FR-2: MUST 목록은 로그인 없이 보인다
- FR-3: MUST 기본 목록은 공개된(숨김 아님·승인 강사·대리면 동의) 모집중·마감 임박 클래스 중 시작 전인 것만. 종료·취소·시작한 클래스는 보이지 않는다
- FR-4: MUST 정렬은 시작 시각이 가까운 순 하나. 날짜(한국 시간)별로 묶어 보여준다
- FR-5: MUST 항목에 곡명·아티스트(대표 곡), 날짜·시간, 권역, 강사 이름, 가격, 난이도, 마감 임박 여부를 보여주고, 누르면 클래스 상세로 간다
- FR-6: MUST 20개씩 보여주고 끝에 닿으면 다음 20개를 같은 조건·같은 순서로 이어 붙인다
- FR-7: MUST 날짜 조건은 오늘 / 이번 주(오늘~일요일) / 이번 주말(다가오는 토·일, 일요일이면 오늘) / 직접 고른 날 중 하나. 한국 시간 기준이고, 어느 경우든 시작 전인 것만
- FR-8: MUST 권역은 여러 개를 고를 수 있고, 난이도는 하나다
- FR-9: MUST 검색어는 곡명·아티스트(별칭 포함)에 맞는 곡의 클래스(대표 곡이 아니어도)만 남긴다. 강사 이름은 찾지 않는다
- FR-10: MUST 마감 포함을 켜면 마감(closed) 클래스도 보인다. 흐리게 구분하고, 취소되지 않은 앵콜 수가 있으면 보여준다
- FR-11: MUST 모든 조건은 주소(`?q=&date=&region=&level=&closed=`)에 남고, 모르는 값은 무시한다
- FR-12: MUST 결과가 0개면 조건을 줄여 보라는 안내와 초기화(검색어는 남김)를 보여준다. 검색어에 맞는 곡이 있으면 그 곡 상세로 가는 길도 보여준다
- FR-13: MUST 누가 요청했는지 같은 개인정보는 보이지 않는다

## Constraints (mandatory)

- CON-1: MUST 강사 이름 검색, 다른 정렬, 하단 탭바, 찜은 이번에 없다. 없는 기능의 입구를 두지 않는다
- CON-2: MUST 스키마를 바꾸지 않는다
- CON-3: MUST 목록 항목은 홈과 같은 티켓 부품을 쓴다

## Success Criteria (mandatory)

- SC-1: 조건 없는 목록의 앞 10개가 홈 다가오는 클래스와 같다
- SC-2: 날짜·권역·난이도·검색어·마감 포함 각각이 서버에서 맞는 집합을 돌려준다(되돌리는 트랜잭션 테스트)
- SC-3: 20개 뒤 이어 붙인 결과에 빠지거나 겹치는 항목이 없다
- SC-4: 주소만으로 같은 결과가 열리고, 375px에서 가로로 넘치지 않는다
