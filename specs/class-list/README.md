# 클래스 목록·필터

## Background

지금 클래스를 보는 길은 홈의 "다가오는 클래스" 열 개와 곡 상세의 "다가오는 클래스"뿐이다. "이번 주말에 홍대에서 들을 수 있는 입문 클래스"처럼 언제·어디서·어느 정도를 기준으로 고르는 길이 없고, 검색은 곡으로만 이어진다. 원데이 클래스는 "언제"가 가장 큰 기준이라, 날짜로 훑고 동네·난이도로 좁히는 목록이 있어야 수강생이 실제로 갈 수 있는 클래스를 찾는다(F-03).

## Goal

열린 클래스를 날짜 순으로 보고, 검색어·날짜·권역·난이도로 좁혀서, 바로 클래스 상세로 간다.

## How it works

### 목록 보기

- 홈 다가오는 클래스의 더보기, 검색에서 엔터로 들어간다. 로그인 없이 누구나 본다.
- 아직 시작하지 않은 모집중·마감 임박 클래스가 가까운 날짜 순으로 보인다. 날짜별로 묶여 있어 훑기 쉽다.
- 각 클래스에 곡명·아티스트, 날짜·시간, 권역, 강사, 가격, 난이도, 마감 임박 여부가 보인다. 누르면 클래스 상세로 간다.
- 20개씩 보여주고, 끝까지 내리면 다음 20개가 이어진다.
- 종료됐거나 취소된 클래스는 보이지 않는다.

### 좁히기

- 검색어: 곡명·아티스트(별칭 포함)로 그 곡의 클래스만 본다. 검색 화면에서 엔터를 치면 그 검색어가 담긴 목록으로 온다.
- 날짜: 오늘 / 이번 주 / 이번 주말 / 날짜 직접 고르기. 기본은 오늘 이후 전체.
- 권역: 여러 곳을 고를 수 있다. 기본은 전체.
- 난이도: 입문 / 초급 / 중급 이상 중 하나. 기본은 전체.
- 마감 포함: 켜면 마감된 클래스도 흐리게 보인다. 앵콜이 모이고 있으면 그 수가 보인다. 누르면 클래스 상세(앵콜)로 간다.
- 고른 조건은 모두 주소에 남는다. 새로 고치거나 공유해도 같은 결과가 보인다.

### 결과가 없을 때

- 조건에 맞는 클래스가 없으면 조건을 줄여 보라는 안내와 조건 초기화가 보인다.
- 검색어로 찾은 곡에 클래스가 없으면 그 곡의 상세(추가요)로 가는 길이 보인다.

### 이번에 하지 않는 것

- 강사 이름 검색 (강사 프로필 F-21과 함께)
- 다른 정렬 (MVP는 가까운 날짜순 하나)
- 하단 탭바 (탭바를 만들 때 찾기 탭이 검색·목록이 된다)
- 날짜 선택 달력 UI 꾸미기 (브라우저 기본 날짜 입력을 쓴다)
