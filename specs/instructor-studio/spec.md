# Feature Specification: 강사·스튜디오 자세히 보기

## Overview

강사가 연습실을 "내 스튜디오"로 한 번 등록해 계속 쓰고, 수강생은 클래스 상세에서 연습실 위치·시설·사진과 강사 소개·영상을 보고 클래스를 고른다. 지금은 운영자가 강사를 대신해 입력한다.

## User Scenarios & Testing (mandatory)

### User Story 1: 운영자가 강사의 스튜디오를 등록한다

- As: 운영자는
- I: 연습실 이름을 검색해 고르는 것만으로 강사의 스튜디오를 등록할 수 있다
- So: 주소를 손으로 치지 않고 정확한 위치를 남기기 위해

#### Acceptance Scenarios

Scenario 1: **카카오맵 장소로 등록**

- Given: 카카오맵에 있는 연습실일 때
- When: 운영자가 연습실 이름으로 검색해 하나를 고르면
- Then: 이름·주소·위치·장소 링크가 채워진 스튜디오가 그 강사 목록에 생기고, 권역이 주소로 정해진다

Scenario 2: **주소로 등록**

- Given: 카카오맵에 없는 연습실일 때
- When: 운영자가 주소를 검색해 고르고 스튜디오 이름을 넣으면
- Then: 이름·주소·위치가 있는 스튜디오가 생긴다 (장소 링크는 없다)

Scenario 3: **같은 장소 두 번**

- Given: 그 강사에게 이미 같은 카카오맵 장소의 스튜디오가 있을 때
- When: 같은 장소를 또 고르면
- Then: 새로 만들지 않고 이미 있는 스튜디오를 쓴다

Scenario 4: **시설과 사진**

- Given: 스튜디오가 있을 때
- When: 운영자가 시설을 고르고 사진을 올리면
- Then: 저장되고, 그 스튜디오를 쓰는 클래스 상세에 바로 나온다

Scenario 5: **목록에서 빼기**

- Given: 더 쓰지 않는 스튜디오일 때
- When: 목록에서 빼면
- Then: 클래스 등록에서 고를 수 없지만, 그 스튜디오로 열린 클래스 상세는 그대로 보인다

Scenario 6: **운영자가 아닐 때**

- Given: 운영자가 아니거나 로그인하지 않았을 때
- When: 스튜디오·사진·프로필 기능을 직접 부르면
- Then: 거절되고 아무것도 바뀌지 않는다

### User Story 2: 클래스 등록에서 스튜디오를 고른다

- As: 운영자는
- I: 클래스를 등록할 때 강사의 스튜디오를 고르거나 그 자리에서 새로 찾아 추가할 수 있다
- So: 같은 연습실 정보를 다시 넣지 않기 위해

#### Acceptance Scenarios

Scenario 1: **최근 스튜디오가 기본**

- Given: 강사에게 스튜디오가 여러 개일 때
- When: 클래스 등록을 열면
- Then: 가장 최근에 쓴 스튜디오가 골라져 있다

Scenario 2: **그 자리에서 추가**

- Given: 원하는 스튜디오가 목록에 없을 때
- When: 검색해 고르면
- Then: 내 스튜디오에 저장되고 이 클래스의 장소로 골라진다

### User Story 3: 수강생이 연습실을 살펴본다

- As: 수강생은
- I: 클래스 상세에서 연습실 위치·시설·사진을 볼 수 있다
- So: 갈 만한 곳인지 판단하기 위해

#### Acceptance Scenarios

Scenario 1: **지도 미리보기**

- Given: 위치가 있는 스튜디오의 클래스일 때
- When: 장소 섹션을 보면
- Then: 연습실에 핀이 꽂힌 지도 미리보기가 보이고, 누르면 카카오맵이 열린다. 미리보기는 끌어도 움직이지 않는다

Scenario 2: **위치가 없을 때**

- Given: 위치가 없는 장소(예전 클래스)일 때
- When: 장소 섹션을 보면
- Then: 미리보기 없이 이름·주소·카카오맵 열기·주소 복사가 보인다

Scenario 3: **시설**

- Given: 시설을 고른 스튜디오일 때
- When: 장소 섹션을 보면
- Then: 고른 시설이 이름으로 보인다

Scenario 4: **사진 보기**

- Given: 사진이 3장 있는 스튜디오일 때
- When: 작은 사진 하나를 누르면
- Then: 그 사진이 크게 열리고, 옆으로 넘겨 다른 사진을 보고, 닫기 버튼·Esc·휴대폰 뒤로 가기로 닫힌다

Scenario 5: **카카오맵 사진·리뷰**

- Given: 카카오맵 장소로 등록한 스튜디오일 때
- When: 장소 섹션을 보면
- Then: "카카오맵에서 사진·리뷰 보기"로 그 장소 페이지에 갈 수 있다

### User Story 4: 수강생이 강사를 알아본다

- As: 수강생은
- I: 클래스 상세에서 강사 사진·소개·포트폴리오 영상을 볼 수 있다
- So: 어떤 강사에게 배우는지 알고 고르기 위해

#### Acceptance Scenarios

Scenario 1: **강사 정보가 다 있을 때**

- Given: 사진·소개·영상 2개가 있고 공개할 수 있는 강사일 때
- When: 강사 섹션을 보면
- Then: 사진, 활동명, 인스타 아이디, 소개, 영상 2개(누르면 재생, 출처 표시)와 인스타그램 더 보기가 보인다

Scenario 2: **비어 있을 때**

- Given: 아무것도 넣지 않은 강사일 때
- When: 강사 섹션을 보면
- Then: 이름 첫 글자 동그라미, 활동명, 인스타 아이디, 인스타그램 더 보기만 보인다

Scenario 3: **사진·영상 게재 동의 없음**

- Given: 대리 등록 강사이고 사진·영상 게재 동의가 없을 때
- When: 강사 섹션을 보면
- Then: 넣어 둔 사진·소개·영상이 있어도 보이지 않는다

Scenario 4: **막힌 영상**

- Given: 퍼가기가 막힌 YouTube 링크일 때
- When: 운영자가 포트폴리오로 넣으면
- Then: 저장되지 않고 이유를 안내받는다

## Functional Requirements (mandatory)

- FR-1: MUST 스튜디오는 강사에 속하고, 카카오맵 장소 검색이나 주소 검색으로 고른 결과로 만든다 (이름·주소·위도·경도, 카카오 장소면 장소 id·링크)
- FR-2: MUST 같은 강사 안에서 같은 카카오 장소는 하나의 스튜디오다
- FR-3: MUST 스튜디오의 권역은 주소로 정하고 운영자가 바꿀 수 있다
- FR-4: MUST 시설은 정해진 목록(거울, 마루 바닥, 매트, 탈의실, 샤워실, 주차, 엘리베이터, 냉난방)에서 고른다
- FR-5: MUST 스튜디오 사진은 최대 8장, 강사 프로필 사진은 1장. 올릴 때 화면용 큰 사진과 목록용 작은 사진 두 크기로 줄인다. 이미지(jpg·png·webp)만 받는다
- FR-6: MUST 목록에서 뺀 스튜디오는 클래스 등록에서 고를 수 없고, 그 스튜디오를 가리키는 클래스 상세는 그대로 보인다
- FR-7: MUST 클래스 등록은 강사의 스튜디오(목록에서 빼지 않은 것) 중 최근 순으로 고르고, 그 자리에서 검색해 추가할 수 있다
- FR-8: MUST 클래스 상세의 장소 이름·주소는 클래스에 저장된 값, 지도·시설·사진·장소 링크는 스튜디오의 지금 값이다
- FR-9: MUST 지도 미리보기는 정적(움직이지 않음)이고 누르면 카카오맵이 열린다. 장소 섹션이 화면에 들어올 때만 불러온다. 위치나 지도 키가 없으면 보이지 않는다
- FR-10: MUST 사진 크게 보기는 넘기기·닫기 버튼·Esc·뒤로 가기로 닫기를 지원하고, 사진마다 대체 텍스트가 있다
- FR-11: MUST 강사 소개는 50자(기존 칸), 포트폴리오는 퍼가기가 허용된 YouTube 영상 최대 2개
- FR-12: MUST 대리 등록 강사의 사진·소개·영상과 연습실 사진은 사진·영상 게재 동의를 기록했을 때만 보인다
- FR-13: MUST 스튜디오·사진·프로필 기능은 운영자만 쓸 수 있다
- FR-14: MUST 카카오 REST 키는 서버에서만 쓴다

## Constraints (mandatory)

- CON-1: MUST 카카오맵·인스타그램에서 사진·리뷰를 가져오지 않는다. 링크로 보낸다
- CON-2: MUST 지도에서 클래스 찾기(지도 목록)는 만들지 않는다 (MVP 8절)
- CON-3: MUST 강사가 직접 스튜디오·프로필을 관리하는 화면은 이번에 없다 (F-11·F-12)
- CON-4: MUST 여러 강사의 같은 연습실을 하나로 묶지 않는다
- CON-5: MUST 브라우저는 DB·사진 저장소에 직접 쓰지 않는다. 모든 쓰기는 서버를 거친다
- CON-6: MUST 강사 입력 항목은 모두 선택이다. 비어 있어도 클래스는 열린다

## Success Criteria (mandatory)

- SC-1: 운영자가 카카오맵에 있는 연습실을 검색 한 번과 고르기 한 번으로 스튜디오로 등록한다
- SC-2: 같은 강사의 두 번째 클래스부터 장소를 다시 입력하지 않는다
- SC-3: 수강생이 클래스 상세를 벗어나지 않고 연습실 위치와 사진, 강사 소개와 영상을 본다
- SC-4: 동의 없는 대리 등록 강사의 사진·영상은 어디에도 나오지 않는다

## OpenAPI Specification (optional)

외부에서 부르는 API는 없다. 서버 액션 목록:

| 이름 | 입력 | 결과 | 권한 |
| --- | --- | --- | --- |
| 스튜디오 찾기 | 검색어, 방식(장소·주소) | 후보 목록(이름·주소·위치·카카오 장소 id·링크) | 운영자 |
| 스튜디오 저장 | 강사 id, 고른 후보, 이름(주소 방식), 권역(선택) | 스튜디오 id | 운영자 |
| 스튜디오 고치기 | 스튜디오 id, 이름, 권역, 시설 | 없음 | 운영자 |
| 스튜디오 목록에서 빼기 | 스튜디오 id | 없음 | 운영자 |
| 스튜디오 사진 올리기 | 스튜디오 id, 큰 사진, 작은 사진 | 사진 id | 운영자 |
| 스튜디오 사진 지우기 | 사진 id | 없음 | 운영자 |
| 강사 프로필 저장 | 강사 id, 소개, 포트폴리오 링크 0~2, 사진·영상 게재 동의 | 없음 | 운영자 |
| 강사 사진 올리기·지우기 | 강사 id, 큰 사진, 작은 사진 | 없음 | 운영자 |
