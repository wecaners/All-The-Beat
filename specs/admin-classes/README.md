# 운영자 클래스 관리

## Background

운영 홈은 다가오는 클래스 30개만 보여주고, 할 수 있는 건 마감하기·마감 풀기뿐이다. 클래스는 이제 운영자 대리 등록 말고도 강사가 직접 올린다(F-12). 잘못 올라온 클래스(예약 링크가 깨짐, 신고, 오타)를 운영자가 바로잡을 길이 없고, 지난 클래스나 특정 강사·곡·권역의 클래스를 찾아보는 화면도 없다(F-17).

## Goal

운영자가 전체 클래스를 조건으로 찾아보고, 문제가 있는 클래스를 숨기거나 예약 링크를 고치거나 마감·종료·취소 처리한다.

## How it works

### 전체 클래스 목록 (운영자)

- 운영 클래스 목록에서 다가오는 것과 지난 것을 포함한 전체를 본다. 상태(모집중·마감 임박·마감·종료·취소), 강사, 곡, 권역, 숨김 여부로 좁힐 수 있고 조건은 주소에 남는다.
- 각 줄에 일시, 클래스 이름, 강사, 권역, 공개 여부(숨김·강사 승인·동의), 상태, 예약 클릭 수, 앵콜 수가 보인다. 운영 홈의 다가오는 클래스 표는 그대로 두고 전체 목록으로 가는 길만 더한다.

### 클래스 손보기 (운영자)

- 클래스 하나를 열면 정보 전체(일시·장소·가격·난이도·정원·곡·설명·예약 링크·강사·누가 올렸는지)와 수강생 화면 링크가 보인다.
- 숨김: 신고나 오류가 있으면 수강생에게 안 보이게 한다. 숨김을 풀 수도 있다. 숨겨도 강사의 내 클래스에는 남는다.
- 예약 링크 수정: 새 주소를 넣으면 유형이 다시 정해진다. http(s)가 아니면 저장되지 않는다.
- 마감·마감 풀기는 지금처럼(앵콜이 시작된 마감은 풀 수 없다).
- 강제 종료: 시간이 아직 안 지났어도 끝난 클래스로 만든다. 되돌릴 수 없다.
- 취소: 사유(강사 요청·오류·기타)를 적고 취소한다. 되돌릴 수 없다. 수강생 화면에 취소로 보인다.
- 되돌릴 수 없는 것(종료·취소)은 한 번 더 묻는다.

### 이번에 하지 않는 것

- 신고 접수 화면(신고는 아직 DM으로 받는다)
- 운영자가 클래스 내용(일시·장소·가격 등)을 고치는 것(강사가 내 클래스에서 고친다. 대리 등록 클래스는 등록 폼을 다시 쓴다)
- 숨김·취소를 강사에게 알리기(F-20)
