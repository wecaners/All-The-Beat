# 회원 탈퇴

## Background

기능명세 F-09·F-10은 마이에서 탈퇴할 수 있어야 한다고 정했지만, 마이페이지를 만들 때(specs/my-page) 탈퇴는 "로그인 계정 삭제 방법, 카카오 연결 끊기, 남길 기록 범위가 정해지지 않아" 출시 전 할 일로 미뤘다. 지금 개인정보처리방침은 "탈퇴는 연락처로 요청"하라고 안내한다. 사용자가 스스로 떠날 수 없는 서비스는 출시할 수 없고, 카카오 로그인 문서는 서비스 탈퇴 과정에 카카오 연결 끊기를 반드시 넣으라고 요구한다.

## Goal

로그인한 사용자가 마이에서 직접 탈퇴하면 올빗에 남긴 개인 정보가 지워지고 카카오와의 연결도 끊긴다.

## How it works

### 탈퇴하기 (수강생)

- 마이에서 탈퇴를 고르면 무엇이 지워지는지 한 번 더 보여주고 확인을 받는다. 되돌릴 수 없다는 것도 같이 말한다.
- 확인하면 바로 탈퇴되고 로그아웃된 채로 홈으로 간다. 탈퇴됐다는 안내를 받는다.
- 같은 카카오 계정으로 다시 로그인하면 처음 가입하는 사람처럼 약관 동의부터 다시 한다. 예전 추가요·앵콜은 돌아오지 않는다.

### 무엇이 지워지고 무엇이 남는가

| 대상 | 탈퇴하면 |
| --- | --- |
| 회원 정보(닉네임·프로필 사진·약관 동의 기록), 로그인 계정 | 지운다 |
| 추가요·앵콜 | 지운다. 곡·클래스의 숫자에서도 빠진다 |
| 접속 날짜 기록(재방문 지표) | 지운다 |
| 예약 링크 클릭 기록 | 누가 눌렀는지만 지우고 클릭 수는 남긴다 |
| 내가 만든 곡 | 곡은 남기고 누가 만들었는지만 지운다 |
| 카카오 연결 | 끊는다(카카오에서 올빗 연결이 사라진다) |

- 기존 설계(ERD 7절)는 회원 정보를 남긴 채 닉네임만 지우는 방식이었다. 이번에는 회원 정보와 로그인 계정을 통째로 지운다. 남겨 둘 이유가 없고, 남기면 같은 카카오 계정으로 다시 로그인할 때 지운 계정으로 들어가게 되기 때문이다.

### 강사가 탈퇴하면

- 강사의 클래스는 바로 수강생 화면에서 숨겨지고, 강사 상태는 정지로 바뀐다. 강사 소개·사진·클래스 기록은 운영 화면에 남는다.
- 기획서(F-09)의 "30일 뒤 삭제"는 이번에 하지 않는다. 정해진 시각에 도는 작업이 아직 없어서다. 운영자가 필요할 때 지운다.

### 운영자는 탈퇴할 수 없다

- 운영자 계정은 탈퇴 대신 먼저 운영자 권한을 내려놓아야 한다. 하나뿐인 운영자 계정이 실수로 사라지는 것을 막는다.

### 카카오 연결 끊기가 실패하면

- 올빗의 정보는 그래도 지운다. 실패한 사실은 서버 기록에 남기고, 운영자가 카카오 쪽 연결을 따로 끊는다.

### 개인정보처리방침

- "탈퇴는 연락처로 요청"을 "마이에서 직접 탈퇴"로 바꾸고, 탈퇴 때 지우는 것과 남기는 것을 위 표와 맞춘다.
- 운영자 지표(specs/admin-metrics)가 새로 쓰는 쿠키(`ab_visit`)와 접속 날짜 기록이 방침에 빠져 있어 이번에 같이 적는다.

### 이번에 하지 않는 것

- 탈퇴 사유 받기, 탈퇴 철회·유예 기간
- 강사 클래스·강사 정보의 30일 뒤 자동 삭제
- 운영자가 다른 사용자를 탈퇴시키는 기능
