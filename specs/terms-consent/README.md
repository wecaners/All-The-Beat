# 약관 동의

## Background

올빗은 카카오 로그인으로 카카오 회원번호·닉네임·프로필 사진을 받고, 추가요·앵콜에 남긴 권역·시간대·한마디를 저장하며, 예약 링크 클릭을 세려고 쿠키를 남긴다. 이런 수집과 이용은 사용자에게 알리고 동의를 받아야 하고, 이용약관과 개인정보처리방침은 출시 전에 게시해야 한다(기획서 리스크, F-09).

지금은 카카오 로그인이 끝나면 바로 원래 화면으로 돌아와 아무 동의 없이 추가요·앵콜을 남길 수 있다. 동의 시각을 기록할 자리는 처음부터 있었지만(`profiles`), 채우는 화면이 없다. 마이에서 약관을 볼 길도 없다.

## Goal

처음 로그인한 사용자에게 이용약관·개인정보 동의를 한 번 받고, 누구나 약관과 개인정보처리방침을 볼 수 있게 한다.

## How it works

### 첫 로그인 때 동의

- 카카오 로그인이 끝나고 돌아올 때, 아직 동의하지 않은 사용자에게는 원래 화면 대신 동의 화면이 먼저 나온다. "처음이시군요! 약관에 동의하면 바로 시작돼요"처럼 짧게 말한다.
- 필수 동의 두 개(이용약관, 개인정보 수집·이용)와 선택 동의 하나(새 클래스·이벤트 소식 받기)가 있고, 전체 동의로 한 번에 고를 수 있다. 각 약관은 그 자리에서 열어 볼 수 있다.
- 필수 두 개에 동의하면 원래 가려던 화면으로 돌아가고, 하려던 일(추가요 시트 자동 열기 등)이 이어진다.
- 동의한 시각을 항목별로 기록한다. 선택 동의는 하지 않아도 되고, 동의하지 않은 채 돌아가면 기록하지 않는다.
- 이미 동의한 사용자에게는 다시 묻지 않는다.

### 동의 없이는 요청을 남기지 못한다

- 동의 화면에서 벗어나 다른 화면으로 가는 것은 막지 않는다. 둘러보기는 로그인·동의 없이도 된다.
- 다만 동의하지 않은 사용자가 추가요·앵콜을 남기려 하면 동의 화면으로 보내고, 동의하면 하려던 화면으로 돌아온다.
- 이 기능 전에 로그인한 사용자도 같다. 다음에 로그인하거나 추가요·앵콜을 남길 때 한 번 동의한다.

### 약관 보기

- 이용약관과 개인정보처리방침은 로그인 없이 누구나 볼 수 있는 화면이다.
- 마이(로그인 전·후 모두)와 동의 화면에서 들어갈 수 있다.
- 개인정보처리방침에는 실제로 하는 일만 쓴다: 카카오에서 받는 항목, 추가요·앵콜 내용, 예약 클릭을 세는 쿠키, 보관 기간, 맡기는 곳(Supabase·Vercel·카카오), 탈퇴 시 처리.
- 두 문서는 초안이다. 운영자 이름·연락처처럼 아직 정해지지 않은 것은 빈칸으로 두고, 출시 전에 사용자가 검토해 채운다.

### 마케팅 수신 동의

- 선택 동의를 받아 기록만 한다. 소식을 보내는 기능(알림 F-20)은 아직 없으므로 "받을 수 있다"고만 말하고, 언제 무엇을 보내는지는 약속하지 않는다.
- 마이에서 선택 동의를 바꾸는 것은 알림 기능과 함께 한다.

### 이번에 하지 않는 것

- 회원 탈퇴 (F-09, 따로)
- 마케팅 수신 동의 변경, 약관 개정 시 재동의 (개정이 생길 때)
- 문의하기 (연락처가 정해지면)
- 약관 문서의 법률 검토. 초안은 올빗이 실제로 하는 일을 바탕으로 쓰되, 최종 문구는 사용자가 확인한다
