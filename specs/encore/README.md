# 앵콜

## Background

인기 있는 원데이 클래스는 금방 마감되고, 한 번 끝나면 다시 열리는지 알 길이 없다. 놓친 수강생은 강사 인스타그램을 계속 지켜보거나 그냥 포기한다.

강사 쪽에서도 "다시 열면 올 사람이 있을까"를 모른 채 다음 클래스를 정한다. 마감된 클래스에 몰렸던 관심이 어디에도 남지 않고 사라진다.

추가요는 곡에 대한 요청이라 "이 강사의 이 클래스를 한 번 더"라는 마음을 담지 못한다. 앵콜은 마감·종료된 클래스에 관심을 모아 같은 강사에게 전달하고, 같은 클래스를 새 날짜로 다시 여는 데까지 잇는다. 마감이라는 끝을 다음 클래스의 수요로 바꾸는 장치다.

지금 올빗에는 강사가 직접 들어오는 화면과 알림이 없다. 그래서 앵콜이 기준 인원에 닿으면 운영자가 강사에게 직접 연락하고, 강사의 답을 운영자가 대신 남긴다. 수강생 화면은 이렇게 실제로 일어난 일만 말한다(제품 원칙 6).

## Goal

수강생은 놓친 클래스에 앵콜을 남기고 진행 상황을 보며, 운영자는 기준에 닿은 앵콜을 강사에게 전해 앵콜 클래스로 잇는다.

## How it works

### 앵콜 남기기

- 마감됐거나 끝난 지 30일이 안 된 클래스에서 앵콜을 남길 수 있다.
- 희망 시간대와 강사에게 남길 한마디(100자)를 고를 수 있고, 둘 다 넣지 않아도 된다.
- 로그인이 필요하다. 로그인하지 않았으면 추가요와 같은 카카오 로그인을 거쳐 그 클래스로 돌아온다.
- 한 사람은 한 클래스에 앵콜을 한 번만 남긴다. 다시 남기면 희망 시간대·한마디가 바뀌고 인원은 그대로다.
- 앵콜을 남기는 순간은 감정 순간이라, 축하 움직임으로 응답한다.
- 앵콜은 예약이 아니라 관심 표시다. 우선 예약 같은 혜택은 약속하지 않는다.

### 진행 상황 보기

- 누구나(로그인 없이도) 지금 앵콜한 사람 수를 본다. 누가 남겼는지는 보이지 않는다.
- 기준 인원에 닿기 전에는 몇 명이 더 모이면 강사에게 전달되는지 보여준다. 기준은 정원의 30%(최소 3명), 정원이 없으면 5명이다.
- 기준에 닿으면 "강사님께 전달됐다"고 알린다.
- 강사가 검토하겠다고 답한 뒤에만 "검토 중"이라고 알린다. 기준만 넘었을 때는 쓰지 않는다.
- 강사가 이번엔 어렵다고 답하면 그렇게 알리고, 같은 곡의 다른 클래스와 그 곡 추가요로 안내한다.
- 끝난 지 30일이 지나면 앵콜을 더 받지 않고, 같은 곡의 다른 클래스와 추가요로 안내한다.
- 진행 상태는 뒤로 가지 않는다. 전달된 뒤 취소로 인원이 기준 아래로 내려가도 전달됨·검토 중은 그대로다. 인원은 언제나 지금 실제 인원을 보여준다.

### 앵콜 취소

- 남긴 앵콜은 언제든 취소할 수 있다.
- 이미 강사에게 전달됐거나 검토 중이면 취소하기 전에 한 번 더 묻는다. "취소하면 강사님이 보는 앵콜 인원에서 빠져요"처럼 사실만 말한다.

### 운영자가 강사에게 전하기

- 운영자는 기준 인원에 닿고 강사가 아직 답하지 않은 앵콜 목록을 본다. 대리 등록 강사의 클래스도 똑같이 나온다.
- 클래스마다 앵콜 인원, 희망 시간대 분포, 최근 한마디 5개를 본다.
- 운영자가 강사에게 연락한 뒤 강사의 답을 대신 남긴다: 검토할게요, 이번엔 어려워요.
- 검토가 시작되면 그때 인원을 기억해 두고, 이후에는 "검토 시작 때 14명 · 지금 12명"처럼 두 숫자를 같이 본다.
- 강사에게 전할 때 쓰도록 "앵콜은 예약이 아니라 관심 표시예요. 앵콜한 분 전원이 예약하지는 않을 수 있어요" 안내를 함께 보여준다.

### 앵콜 클래스 열기

- 운영자는 앵콜이 모인 클래스에서 앵콜 클래스를 등록한다. 원 클래스의 곡·장소·가격·예약 링크가 미리 채워져 있고 날짜만 넣으면 된다.
- 앵콜 클래스를 등록하면 원 클래스에 앵콜한 모든 사람에게 "앵콜 클래스가 열렸어요"가 보이고, 원 클래스에서 새 클래스로 갈 수 있다.
- 새 클래스에는 앵콜 클래스라는 표시와 원 클래스로 가는 길이 있다.
- 앵콜 클래스가 다시 마감되면 그 클래스에서 새 앵콜이 시작된다.

### 클래스 마감 처리

- 지금은 클래스를 마감으로 바꾸는 방법이 없어, 끝난 클래스에만 앵콜을 남길 수 있다. 운영자가 클래스를 마감으로 바꿀 수 있게 한다(F-17의 일부).

### 이번에 하지 않는 것

- 강사가 직접 앵콜을 보고 답하는 화면 (강사 화면 T-03, F-11·F-12와 함께)
- 강사·수강생에게 가는 알림 (F-20). 수강생은 클래스 상세에서 상태를 확인한다
- 마이페이지의 "내 앵콜" 모아 보기 (F-10과 함께)
- 검토 중 14일 무응답 시 운영자에게 알리기 (알림 기능과 함께). 대신 운영자 목록에서 검토 시작 날짜를 본다
- 앵콜 참여자 우선 예약, 인원 확정, 예약금 (결제 내재화 이후)
- 운영자 지표 화면 전체 (F-18). 이번에는 앵콜 목록만 만든다
