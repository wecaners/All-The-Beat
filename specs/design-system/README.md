# 디자인 시스템 (덕질 스크랩북)

## Background

올빗은 곡과 안무 영상이 주인공인 서비스라, 화면이 예쁘고 캡처해서 올리고 싶어야 사람이 모이고 퍼진다. 지금까지 만든 화면은 기능만 동작하는 임시 모양이라, 화면이 늘어날수록 제각각의 스타일이 쌓이고 나중에 전부 다시 칠해야 한다.

디자인 시안 1~4차에서 "덕질 스크랩북" 컨셉(밝고 귀엽고 키치한 스티커·포토카드·티켓)과 인터랙션 방향을 정했다. 이 결정을 코드의 공통 재료로 만들어 두면, 이후 모든 화면이 같은 말투로 빠르게 만들어진다.

## Goal

시안에서 정한 색·글꼴·형태·움직임을 앱의 공통 토큰과 컴포넌트로 만들고, 곡 상세 화면에 먼저 적용한다.

## How it works

### 토큰

- 색, 글꼴, 테두리, 그림자, 모서리, 움직임 속도를 한 곳에서 정의하고 모든 화면이 가져다 쓴다.
- 배경은 크림 속지 위의 모눈 점, 큰 면적의 색은 한 화면에 핑크 하나.

### 컴포넌트

- 스티커 버튼, 칩, 바텀시트, 포토카드, 클래스 티켓, 별 스티커, 작은 스티커 라벨, 터지는 하트·별을 공통 부품으로 쓴다.
- 누르면 도장처럼 꾹 눌리고, 감정 순간(추가요 완료)에는 스티커가 쾅 붙고 하트·별이 터진다.
- 기기에서 "동작 줄이기"를 켠 사람에게는 움직임을 끈다.

### 곡 상세 적용

- 영상은 포토카드에 담기고, 누를 때 재생된다. 마우스·손가락 움직임에 따라 홀로그램처럼 반짝인다.
- 기다리는 사람 수, 추가요 버튼, 다가오는 클래스 티켓이 새 모양으로 바뀐다.
- 처음 추가요를 남기면 완료 순간이 펼쳐지고, 몇 번째로 기다리는지 보여준다.

### 이번 범위 밖

- 홈·검색·클래스 상세 등 다른 화면 (토큰·컴포넌트가 생긴 뒤 각 기능에서 적용)
- 다크 모드 (스크랩북 컨셉은 밝은 화면만)
- 3D 에셋, 마스코트
