# Feature Specification: 디자인 시스템 (덕질 스크랩북)

## Overview

시안 2·3차에서 확정한 비주얼과 인터랙션을 공통 토큰·컴포넌트로 만들고 곡 상세(U-04)와 추가요 시트(U-07)에 적용한다.

## User Scenarios & Testing (mandatory)

### User Story 1: 곡 상세가 스크랩북처럼 보인다

- As: 수강생은
- I: 곡 상세에서 포토카드에 담긴 안무 영상과 기다리는 사람 수를 한눈에 볼 수 있다
- So: 이 곡 클래스가 얼마나 기다려지는지 느끼고 추가요를 남기기 위해

#### Acceptance Scenarios

Scenario 1: **영상 있는 곡**

- Given: 대표 영상이 지정된 곡일 때
- When: 곡 상세를 열면
- Then: 영상 썸네일이 포토카드에 담겨 보이고, 누르면 그 자리에서 재생된다

Scenario 2: **영상 없는 곡**

- Given: 대표 영상이 없는 곡일 때
- When: 곡 상세를 열면
- Then: 영상 자리에 영상이 아직 없다는 안내가 담긴 카드가 보인다

### User Story 2: 추가요가 즐거운 순간이 된다

- As: 수강생은
- I: 추가요를 처음 남기면 완료를 축하받고 몇 번째로 기다리는지 안다
- So: 내 요청이 실제로 쌓였다고 느끼기 위해

#### Acceptance Scenarios

Scenario 1: **첫 추가요**

- Given: 이 곡에 추가요를 남긴 적 없거나 취소했던 사용자일 때
- When: 추가요를 제출하면
- Then: 완료 순간이 펼쳐지고 "N번째로 기다리는 중"을 보며, 닫으면 기다리는 사람 수가 1 늘어 있다

Scenario 2: **수정**

- Given: 이미 추가요를 남긴 사용자일 때
- When: 권역·시간대를 바꿔 제출하면
- Then: 완료 순간 대신 수정됐다는 짧은 안내를 받는다

Scenario 3: **동작 줄이기**

- Given: 기기에서 동작 줄이기를 켠 사용자일 때
- When: 추가요를 남기면
- Then: 같은 정보를 받지만 화면 흔들림·터짐·튕김 움직임은 없다

## Functional Requirements (mandatory)

- FR-1: MUST 색·글꼴·테두리·그림자·모서리·움직임 속도를 공통 토큰으로 정의하고 화면은 토큰만 쓴다
- FR-2: MUST 한글 웹폰트는 화면에 쓰인 글자만 받도록 나눠 받는다
- FR-3: MUST 영상은 누르기 전까지 YouTube 플레이어를 불러오지 않는다 (썸네일만)
- FR-4: MUST 첫 추가요(새로 만들거나 취소 후 다시)일 때만 완료 순간을 보여주고, 순번은 그 곡의 최근 90일 유효 추가요 중 내 순서다
- FR-5: MUST 동작 줄이기 설정이면 장식 움직임을 끈다
- FR-6: SHOULD 스티커형 버튼은 누르면 도장처럼 눌린다

## Constraints (mandatory)

- CON-1: MUST 아직 없는 기능(알림)을 약속하는 문구를 쓰지 않는다 (MVP 원칙 6)
- CON-2: MUST 밝은 화면만 지원한다 (다크 모드 없음)
- CON-3: MUST 3D 에셋을 쓰지 않는다

## Success Criteria (mandatory)

- SC-1: 곡 상세가 시안 2차와 같은 말투(포토카드·스티커·티켓)로 보인다
- SC-2: 곡 상세 첫 화면이 YouTube 플레이어 없이 뜬다
- SC-3: 첫 추가요에서 완료 순간과 순번이 보인다
