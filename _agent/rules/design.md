# 디자인 규칙 — 덕질 스크랩북

수강생 화면(UI)을 만들거나 고칠 때 읽는다. 결정 과정과 시안은 `design/README.md`, `design/concepts/`에 있다.
운영 화면(`/admin`)은 내부 도구라 이 규칙을 따르지 않고 단순한 폼을 쓴다. 오래 보는 화면이라 어둡게 둔다(`globals.css`의 `.admin-dark`가 zinc 색 변수를 뒤집는다. 운영 화면은 Tailwind zinc 색만 쓰고 `dark:` 짝은 붙이지 않는다).

## 컨셉

> 좋아하는 곡의 **포토카드**를 붙이고, 클래스 **티켓**을 끼우고, **형광펜과 스티커**로 꾸민 다꾸 다이어리.

밝고 귀엽고 키치하게. 모든 요소는 이 문장에서 나와야 한다. 새 요소를 만들 때 "스크랩북에 있을 물건인가?"를 먼저 묻는다.

| 무엇 | 스크랩북에서 | 화면에서 |
| --- | --- | --- |
| 배경 | 다이어리 속지 | `bg-paper` (크림 + 모눈 점) |
| 곡 | 포토카드 | 흰 테두리 카드 + 테이프, 살짝 기울임 (`VideoCard`) |
| 클래스 | 공연 티켓 | 날짜가 크게 찍힌 절취선 티켓 (`ClassTicket`) |
| 감정 순간 | 스티커 | 별 스티커·버블 글씨·핑크 (`StarBurst`, `Celebration`) |
| 강조 | 형광펜 | `mark-lime` |

## 토큰

`app/src/app/globals.css`의 `@theme`이 기준이다. 화면에서 색 코드·그림자 값을 직접 쓰지 않고 토큰 클래스를 쓴다.

- 색 (역할 이름): `paper` 배경, `card` 붙인 카드, `ink` 테두리·글자, `sub` 보조 글자, `pink` 추가요·행동, `lime` 형광펜·완료, `sky`·`butter`·`lilac` 스티커·칩, `pink-soft` 옅은 바탕, `kakao` 카카오 버튼
- **큰 면적에 칠하는 색은 한 화면에 `pink` 하나.** 나머지 색은 스티커·칩·작은 면적에만
- 글꼴: `font-display`(메이플스토리 Bold) 로고·외침·곡 제목·큰 숫자·버튼 / `font-zine`(Bricolage) 영문 대문자 라벨 / 기본(Pretendard) 본문·정보. 한글 디스플레이 폰트는 하나만 쓴다. 섞으면 화면이 산만해지고 오래 볼 때 피로하다
- 줄바꿈은 전역(`body`)에서 어절 단위(`keep-all`)다. 화면마다 `break-keep`을 따로 붙이지 않는다
- 메이플스토리 서체는 약관상 파일을 수정(서브셋·변환)해 배포할 수 없다. `app/src/app/fonts/`의 원본 woff를 그대로 쓰고, 서비스 안에 저작권 표기("메이플스토리 서체 © NEXON Korea")를 둔다
- 테두리는 2px `ink`, 그림자는 딱 떨어지는 `shadow-sticker-sm|sticker|sticker-lg`. 흐린 그림자(blur)는 쓰지 않는다
- 유틸: `sticker-edge`(테두리+그림자), `press`(누르면 꾹), `mark-lime`(형광펜), `text-sticker`(외곽선 글씨). 별 스티커는 SVG 컴포넌트 `StarBurst`(CSS clip-path로 자르면 테두리가 계단처럼 깨진다)

새 화면은 이 부품부터 쓰고, 없으면 여기에 추가한다. 화면 파일 안에 비슷한 것을 따로 만들지 않는다.

| `StaticMap` | 연습실 위치 미리보기(카카오 정적 지도, 보일 때만 로드, 누르면 카카오맵). 키·위치가 없으면 안 그린다 |
| `PhotoStrip` | 작은 사진 목록 + 크게 보기(`<dialog>`, 넘기기·닫기·Esc·뒤로 가기) |

## 움직임

- 버튼·카드는 누르면 도장처럼 눌린다(`press`).
- **크게 터지는 움직임(스티커 쾅, 하트·별 터짐, 화면 흔들림, 진동)은 감정 순간에만**: 추가요 완료, 앵콜, 순위 상승. 평소 정보 화면에는 쓰지 않는다.
- 평소 움직임은 아주 작게: 반짝임, 숨쉬기, 천천히 도는 스티커.
- 화면 전환·버튼 반응은 0.3~0.4초 안에 끝낸다. 예약처럼 중요한 동선을 애니메이션으로 기다리게 하지 않는다.
- `prefers-reduced-motion`이면 장식 움직임을 끈다(`globals.css`, `motion.ts`가 처리). 움직임에만 의존해 정보를 전달하지 않는다.
- 움직임은 Web Animations API와 CSS로 만든다. 애니메이션 라이브러리를 추가하려면 먼저 묻는다.

### 인터랙션 표 (round-3에서 채택한 9가지)

새 화면·부품을 만들 때 이 표에서 해당하는 줄을 찾아 같이 넣는다. 화면이 생겨서 붙일 수 있게 되면 상태를 고친다. 원본 움직임은 `design/concepts/round-3.html`.

| 인터랙션 | 붙는 곳 | 상태 |
| --- | --- | --- |
| 착착 붙기 | 목록 항목에 `animate-stick-in` + `stagger(i)`(`motion.ts`). 로고는 누르면 0.4초 흔들림(`Logo`) | 홈·곡 상세 목록, 로고 |
| 포토카드 기울기 | 가로로 넘기는 포토카드 줄은 `TiltRow`로 감싼다 | 홈 핫한 곡 |
| 홀로 포토카드 | 재생하는 영상 카드 `VideoCard` | 곡·클래스 상세 |
| 추가요 클라이맥스 | `BottomSheet`, `ChoiceChip`, `Celebration` | 곡 상세 |
| 티켓 찢기 | `ClassTicket` 자체에 있다(0.35초 뒤 이동, 동작 줄이기면 바로 이동, 새 탭 클릭은 그대로) | 클래스 티켓 전부 |
| 앵콜 응원봉 | 클래스 상세 앵콜 카드의 `Lightstick`(평소엔 살랑임). 처음 앵콜할 때만 응원봉 흔들림 + 아래에서 관객 응원봉 + 숫자 튐 + 작은 색종이 + 진동 | 클래스 상세 (마감·종료) |
| 당겨서 새로고침 | 하지 않는다. 브라우저·인앱 브라우저의 기본 당겨서 새로고침과 부딪히고, 막으면 기본 동작을 잃는다 | 보류 |
| 탭바 알약 | `TabBar` 자체에 있다. 라임 알약이 켜진 탭 아래 있고 누르면 스프링으로 따라가며(0.45초, `motion-safe`) 아이콘이 뛴다. 진동은 없다 | 홈·클래스 목록·추가요 랭킹·마이 |
| 작은 생활 움직임 | 숨쉬는 재생 버튼(`VideoCard`), 살랑이는 스티커(`animate-sway`), 반짝이는 별(`Twinkle`, 화면당 한두 개). 흐르는 글자 띠는 하지 않는다(계속 움직이는 글자, WCAG 2.2.2) | 홈·곡 상세 |
| (안 쓰는 곳) | 검색 결과처럼 칠 때마다 다시 그려지는 목록에는 착착 붙기를 쓰지 않는다 | 검색 |

## 이미지·영상

- 곡 비주얼은 YouTube 공식 안무 영상 썸네일만 쓴다. 앨범 커버는 쓰지 않는다.
- YouTube 플레이어는 사용자가 누를 때만 불러온다(첫 화면 속도).
- 3D 에셋은 쓰지 않는다 (2026-10-28 결정). 시그니처 순간은 평면 스티커와 움직임으로 만든다.

## 문구·접근성

- 문구는 `product.md`를 따른다. 대화체, 짧게, 아직 없는 기능은 약속하지 않는다(원칙 6).
- 장식 요소(테이프, 낙서)는 `aria-hidden`. 아이콘만 있는 버튼에는 `aria-label`.
- 글자 대비: 흰 글씨는 `text-sticker`(검정 외곽선)와 함께 쓴다. 노랑·라임 위 글씨는 `ink`.
- 밝은 화면만 지원한다. 다크 모드는 만들지 않는다.

## 하지 않는 것 (완성도)

- 체크(✓) 같은 기호로 상태를 표시하지 않는다. 고무 도장·스티커와 실제 내용("홍대·합정 · 주말 낮")으로 보여준다.
- 밑줄 텍스트 링크를 버튼 대신 쓰지 않는다. 보조 행동도 스티커 버튼(`white`, `soft`)으로.
- 글자가 있는 요소를 계속 회전시키지 않는다. 살랑임(`animate-sway`)까지만.
- 되돌리기 어려운 행동(추가요 취소 등)은 시트로 한 번 더 묻는다.
