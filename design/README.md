## 결정 (시간 순)

### 컨셉: 덕질 스크랩북 (2026-10-28)

좋아하는 곡의 포토카드를 붙이고, 클래스 티켓을 끼우고, 형광펜과 스티커로 꾸민 다꾸 다이어리.
C(MIXTAPE)의 팬진·티켓 구조를 뼈대로, B(STICKER POP)의 굵은 테두리·딱 떨어지는 그림자·버블 글씨를 주된 말투로 쓴다. 밝고 귀엽고 키치하게.

- 배경: 크림 속지 `#FFF7EC` + 모눈 점
- 곡 = 기울어진 포토카드 + 테이프, 클래스 = 날짜가 큰 절취선 티켓
- 색: 핑크 `#FF6FB5`(추가요·행동), 라임 `#CFF23A`(형광펜·완료), 하늘·버터·라일락은 스티커·칩에만. 큰 면적은 한 화면에 핑크 하나
- 글꼴: Bagel Fat One(외침·제목·큰 숫자), Bricolage Grotesque(팬진 라벨), Pretendard(본문)

### 인터랙션은 적극적으로 (2026-10-28)

round-3의 9가지를 채택한다. 도장 찍는 버튼, 추가요 스티커 쾅·카운트업·터짐, 홀로 포토카드, 티켓 찢기, 앵콜 응원봉, 당겨서 새로고침(스티커 떼기), 탭바 알약, 작은 생활 움직임.
규칙: 크게 터지는 건 감정 순간(추가요·앵콜·완료)에만, 전환·반응은 0.3~0.4초 안, 동작 줄이기 설정 존중.

### 3D 에셋은 쓰지 않는다 (2026-10-28)

round-4에서 부푼 스티커·젤리·클레이 재질을 비교했지만, 품질이 화면의 평면 스티커 언어를 따라오지 못해 쓰지 않기로 한다.
시그니처 순간(추가요 완료, 앵콜 응원봉, 공유 이미지)은 평면 스티커 일러스트와 인터랙션으로 만든다.
마스코트(빗별이)를 둘지는 정하지 않았다. 둔다면 평면 스티커 스타일로 다시 검토한다.

### 디스플레이 폰트를 메이플스토리 Bold로 (2026-10-28)

Bagel Fat One은 귀엽지만 한글 획이 뭉쳐 읽기 어렵고, 오래 머물면 피로하다는 사용자 판단으로 바꾼다. 후보 12종을 곡 상세 화면에 대 본 비교 시안이 `concepts/font-compare.html`에 있다.

- 로고·외침·곡 제목·큰 숫자·버튼을 모두 메이플스토리 Bold 하나로 쓴다. Bagel과 섞지 않는다 (두 굵은 디스플레이 폰트가 한 화면에 있으면 위계가 흐려진다)
- 본문 Pretendard, 영문 라벨 Bricolage는 그대로

### 로고: All the Beat + 모서리 올빗 (2026-10-28)

로고를 영문 "All the Beat"로 바꾸고, 오른쪽 위 모서리에 부르는 이름 "올빗"을 라임색 글씨로 비스듬히 써 붙인다 (사용자 제안, `concepts/logo-compare.html`의 G2).
영문은 화면에서 더 예쁘고, 모서리 글씨 덕에 사람들이 부르는 이름 "올빗"도 같이 익힌다. 상단 높이는 거의 늘지 않는다.

- 상단(24px)에서는 외곽선 1px·그림자 2px로 줄인다. 지금 외곽선(1.6px)은 작은 영문의 e·a 속을 메운다
- 모서리 "올빗"은 상단에서 17px로 확정. 실제 화면에서 15px는 받침이 뭉개져 이름으로 읽히지 않았다
- 탭 제목·공유 미리보기는 "올빗 · All the Beat" 그대로

### 빠진 인터랙션 채우기 (2026-10-28)

화면을 만들며 round-3 인터랙션 일부(티켓 찢기, 착착 붙기, 포토카드 기울기, 반짝임)가 빠진 것을 사용자가 짚었다. 규칙만 적고 "어느 부품에 무엇이 붙는지"를 적지 않은 탓이라, `_agent/rules/design.md`에 인터랙션 표를 두고 채웠다.

- 티켓 찢기는 시안의 0.7초를 0.35초(흔들림 0.09 + 찢김 0.26)로 줄인다 (사용자 결정, 전환 0.3~0.4초 규칙)
- 당겨서 새로고침은 보류한다. 모바일 브라우저·인앱 브라우저의 기본 동작과 부딪힌다
- 흐르는 글자 띠는 하지 않는다. 계속 움직이는 글자는 멈출 방법이 필요하고(WCAG 2.2.2) "글자를 계속 움직이지 않는다" 규칙에 어긋난다
- 로고를 누를 때 시안의 하트·별 터짐과 티켓 찢기의 진동은 뺀다. 크게 터지는 움직임·진동은 감정 순간에만
