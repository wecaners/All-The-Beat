## 결정 (시간 순)

### 컨셉: 덕질 스크랩북 (2026-10-28)

좋아하는 곡의 포토카드를 붙이고, 클래스 티켓을 끼우고, 형광펜과 스티커로 꾸민 다꾸 다이어리.
C(MIXTAPE)의 팬진·티켓 구조를 뼈대로, B(STICKER POP)의 굵은 테두리·딱 떨어지는 그림자·버블 글씨를 주된 말투로 쓴다. 밝고 귀엽고 키치하게.

- 배경: 크림 속지 `#FFF7EC` + 모눈 점
- 곡 = 기울어진 포토카드 + 테이프, 클래스 = 날짜가 큰 절취선 티켓
- 색: 핑크 `#FF6FB5`(추가요·행동), 라임 `#CFF23A`(형광펜·완료), 하늘·버터·라일락은 스티커·칩에만. 큰 면적은 한 화면에 핑크 하나
- 글꼴: Bagel Fat One(외침·제목·큰 숫자), Bricolage Grotesque(팬진 라벨), Pretendard(본문)

### 인터랙션은 적극적으로 (2026-10-28)

round-3의 9가지를 채택한다. 도장 찍는 버튼, 추가요 스티커 쾅·카운트업·터짐, 홀로 포토카드, 티켓 찢기, 앵콜 응원봉, 당겨서 새로고침(스티커 떼기), 탭바 알약, 작은 생활 움직임.
규칙: 크게 터지는 건 감정 순간(추가요·앵콜·완료)에만, 전환·반응은 0.3~0.4초 안, 동작 줄이기 설정 존중.

### 3D 에셋은 쓰지 않는다 (2026-10-28)

round-4에서 부푼 스티커·젤리·클레이 재질을 비교했지만, 품질이 화면의 평면 스티커 언어를 따라오지 못해 쓰지 않기로 한다.
시그니처 순간(추가요 완료, 앵콜 응원봉, 공유 이미지)은 평면 스티커 일러스트와 인터랙션으로 만든다.
마스코트(빗별이)를 둘지는 정하지 않았다. 둔다면 평면 스티커 스타일로 다시 검토한다.
