앵콜을 취소할까요?

취소하면 강사님이 보는
앵콜 인원에서 빠져요.

  1. 취소는 막지 않는다. [앵콜 완료 ✓ · 취소] → 확인 창 "취소하면 강사님이 보는 앵콜 인원에서 빠져요." 사실만 말하고 혜택 상실 같은 위협 문구는 쓰지 않는다 (프로토타입에서 눌러보기).
  2. 취소해도 "검토 중"은 유지되고 숫자만 실제대로 줄어든다. 상태는 뒤로 가지 않는다 (F-24, S-4).
  3. 강사 화면(T-03 B)에는 "검토 시작 시점 14명 · 지금 13명 (취소 1)"과 "앵콜은 예약이 아니라 관심 표시예요" 안내가 고정으로 보인다.
  4. 열렸을 때 알려주는 곳은 MVP에선 이 화면과 마이 > 내 앵콜뿐 (알림 F-20은 Should). "우선 예약" 같은 문구는 쓰지 않는다 (MVP 원칙 6).
  5. "검토 중" 문구는 강사가 [검토할게요]를 누른 뒤에만 나온다 (F-24, 플로우 10). 기준 인원 도달만으로는 "전달됐어요"까지.
  6. 이미 앵콜한 사용자에게는 버튼이 "앵콜 완료 ✓ · 취소"로 바뀐다.
  7. 이후 상태 문구 (화면은 같고 배너만 바뀜):
    · 앵콜 오픈 → "앵콜 클래스가 열렸어요!" + [앵콜 클래스 보기 ›] (새 클래스 U-05, "앵콜 클래스" 배지)
    · 어려워요 → "이번엔 앵콜이 어렵대요" + 같은 곡 다른 클래스 / [이 곡 추가요!]
    · 만료(종료 30일) → 앵콜 블록 숨김
  8. 내 앵콜 목록은 마이(U-09)에서 상태별로 본다.
