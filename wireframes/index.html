  2. 맨 위는 안무 영상 (YouTube 공식 임베드, 자동재생 끔). 들어오자마자 "이 춤을 배우는구나"가 보이게. 왼쪽 위에 영상 유형(안무 연습 / 퍼포먼스 / MV), 아래에 영상 제목·채널과 [YouTube에서 보기].

  4. 곡 상세 안의 클래스 카드는 곡명을 빼고 강사 이름을 제목으로 쓴다 (곡은 이미 화면 제목).
  5. 추가요 수 = 최근 90일, 권역 상위 3개 (F-04). 이미 추가요한 사람에게는 "추가요 완료 ✓ · 취소" (프로토타입에서 눌러보기).
  6. 점선 박스 [강사만] 영역은 승인된 강사 로그인 시에만 보인다 → 클래스 등록 T-02 (곡 미리 선택).
  7. ↗ 공유: 링크 복사 / 인스타 스토리 공유 이미지(F-23, Should).
  8. 결정 필요: 추가요 블록을 클래스 목록 위로 올릴까? (수요 숫자가 강사 유입에는 더 강한 신호)
