# 서비스명 브레인스토밍

- 작성일: 2026-10-26
- 상태: 1차 발산. 후보 압축 → 도메인·상표·인스타 계정 확인은 다음 단계

## 1. 이름이 담아야 할 것 (기획서에서 가져온 기준)

1. **곡 중심** — 강사가 아니라 노래가 주인공
2. **요청** — "이거 해주세요"가 서비스 정체성의 절반
3. **원데이 / 지금 유행** — 가볍고 빠름, 신곡 주기
4. **인스타 친화** — 해시태그·스토리 스티커로 쓰기 좋을 것
5. 나중에 강사 큐레이션(C6)이 붙어도 어색하지 않을 것

## 6. 2차 발산 — "짧게 불렀을 때 입에 붙는가" (2026-10-26 추가)

### 새 기준
사람들은 결국 줄여 부른다 (배달의민족→배민, 오늘의집→오집). 그러니 **처음부터 2음절이거나, 줄였을 때 2음절이 자연스러운** 이름이어야 한다.

| 기준 | 체크 질문 |
|---|---|
| 2음절 | 정식명이 길어도 줄임말이 2음절로 떨어지는가 |
| 발음 | 받침이 적거나, 받침이 있어도 끊어지는 소리(ㄱ·ㅅ·ㅊ)로 경쾌한가 |
| 동사화 | "OO하자", "OO에 올려", "OO 떴다"가 자연스러운가 (토스해, 당근하다처럼) |
| 이중 의미 | 한 단어에 두 가지 뜻이 겹치는가 → 기억에 남는다 |
| 해시태그 | #OO 로 썼을 때 다른 의미로 오염돼 있지 않은가 |

### 1차 후보의 줄임말 점검
| 정식명 | 줄임말 | 판정 |
|---|---|---|
| 킬링파트 | 킬파 | 무난. 다만 "킬"이 세게 들림 |
| 춤신청 | **춤신** | 좋음. "춤의 신"과 겹침 |
| 에잇카운트 | 에카 | 의미가 사라짐. 탈락 |
| 추미 | 추미 | 이미 2음절. 유지 |
| 이번주안무 | 이안? | 의미 없음. 탈락 |
| 오늘춤 | **오춤** | 좋음. "오늘의 춤" 구조가 오늘의집과 같아 익숙 |

### 2음절 신규 후보
| 후보 | 뜻 / 이중 의미 | 입에 붙는 예문 | 메모 |
|---|---|---|---|
| **춤신** | 춤 신청 + 춤의 신 | "춤신에 NEON 올라왔어" | 요청 정체성 + 칭찬어. 이중 의미 가장 강함 |
| **신춤** | 신곡 춤 + 신청 춤 | "신춤 떴다" | 신곡 주기·요청 둘 다 담음. "신난다"의 신 느낌도 |
| **둠칫** | 춤출 때 나오는 의성어 (둠칫둠칫) | "둠칫하러 가자" | 가장 경쾌하고 귀여움. 춤이라는 게 바로 느껴짐. 동사화 최고 |
| **오춤** | 오늘의 춤 | "오춤에서 찾아봐" | 원데이·지금 유행과 맞음 |
| **춤픽** | 춤 + pick (곡을 고른다) | "이번 주 춤픽 뭐야?" | 곡 중심. "~픽"은 이미 익숙한 구조 |
| **춤콜** | 춤 + call (불러낸다) | "춤콜 넣었어" | 요청 정체성. 콜이 배달·택시를 연상시킴 |
| **추미** | 춤 + -i | "추미 깔아" | 외국인 발음 쉬움. 의미는 약함 |
| **들썩** | 몸이 들썩 | "들썩에서 봤어" | 감성 좋음. 서비스 기능은 안 드러남 |

## 7. 3차 발산 — 귀엽고, 키치하고, 확 끌리는 (2026-10-26 추가)

### 새 기준
타깃 10~30대. "설명이 되는 이름"보다 **보는 순간 웃기거나 귀엽거나 따라 말하고 싶은 이름**. 2음절·동사화 기준은 유지.

훅이 생기는 방식 다섯 가지:
1. **귀여운 말투** — 일부러 틀린 맞춤법, 아기 발음 (츔, 추쟈)
2. **의성어·반복** — 소리가 곧 춤 (둠칫둠칫, 추추)
3. **말장난** — 한 단어에 두세 개 뜻 (추가요)
4. **레트로 키치** — 엄마 세대 말을 일부러 쓰는 Y2K 감성 (춤바람)
5. **셀프 디스 밈** — 몸치·뚝딱이처럼 친근한 자조

### 후보

| 방식 | 후보 | 뜻 / 훅 | 예문 · 슬로건 |
|---|---|---|---|
| 귀여운 말투 | **츔** / **츔츔** | "춤"을 귀엽게 뭉갠 인터넷 말투. 한 글자라 로고로 쓰기 좋음 | "츔 추러 가쟈" / "오늘 뭐 츔?" |
| 귀여운 말투 | 추쟈 | "추자"의 애교 발음 | "추쟈! 이번 주 NEON 클래스" |
| 의성어·반복 | **추추 (ChooChoo)** | 춤추 + 기차 소리. 영어로도 귀엽고 발음 쉬움 | "추추 타고 NEON 배우러" |
| 의성어·반복 | 둠칫둠칫 | 비트 소리. 길면 "둠칫" | "둠칫둠칫 할 곡 찾기" |
| 의성어·반복 | 흥칫뿡 | 삐친 척 귀여운 감탄사. "칫"에 비트감 | "흥칫뿡, 내 최애 곡 클래스가 없다고? → 요청하기" |
| 말장난 | **추가요** | ① "추가요!"(하나 더 주세요 = 요청) ② 추(춤) + 가요(K-pop) ③ "춤추러 가요" | "이 곡도 추가요!" — 요청 버튼 문구가 이름이 됨 |
| 말장난 | 춤덕 | 춤 + 덕질. 팬 문화 단어 | "춤덕들의 클래스 지도" |
| 말장난 | 킬포 | 킬링포인트. 팬들이 실제로 쓰는 말 | "킬포만 배우는 원데이" |
| 레트로 키치 | **춤바람** | "춤바람 났다". 촌스러움을 힙하게 | "춤바람 나는 중" / 줄여서 "춤바" |
| 레트로 키치 | 쉐킷 | Shake it을 한글로. 2000~2010년대 K-pop 감성 | "쉐킷하러 가자" |
| 셀프 디스 | **뚝딱** / 뚝딱이 | 몸치를 귀엽게 부르는 말. 초보를 끌어들이는 친근함 | "뚝딱이도 추는 곳" |

### 3차 추천

| 순위 | 후보 | 이유 |
|---|---|---|
| 1 | **추가요** | 서비스의 두 기능(곡으로 찾기, 요청하기)을 말장난 하나로 다 담음. 요청 버튼을 "추가요!"로 쓰면 이름과 기능이 하나가 됨. 줄이면 "추가"로도 통함 |
| 2 | **츔** | 가장 키치하고 귀여움. 한 글자라 로고·앱 아이콘·해시태그에 강함. 기능은 안 드러나므로 슬로건 필요 |
| 3 | **춤바람** | 레트로 키치. 10~30대가 "촌스러워서 힙한" 걸 좋아하는 흐름과 맞음. 다만 3음절 |
| 4 | **뚝딱** | 셀프 디스 밈으로 초보·입문자를 강하게 끌어당김. 타깃을 "몸치 입문자"로 좁히는 효과 |

### 주의
- **츔·뚝딱**은 일상어라 상표 등록·검색 상위 노출이 어려울 수 있음 → "츔츔", "뚝딱댄스"처럼 변형 필요할 수 있음
- **추가요**는 "추가 요금"으로 잘못 읽힐 여지. 로고에서 "추·가요"처럼 끊어 보여주는 디자인으로 해결 가능
- **흥칫뿡·쉐킷**은 기존 노래·밈과 겹쳐 검색 오염 가능성 높음

| 확장성 | ◎ | 장르·지역·국가·사업 범위 어디로 가도 안 막힘. 영어권에서 바로 이해됨 |
| 줄임말 | ○ | "에댄"은 에브리타임→"에타" 패턴이라 10~30대에게 익숙한 구조 |
| 의미 전달 | ○ | 댄스 서비스라는 건 바로 알 수 있음 |
| 귀여움·훅 | △ | 깔끔하지만 무난함. "확 끌리는" 느낌은 약함 |
| 차별성 | △ | 일반명사 조합이라 비슷한 이름이 생기기 쉬움. "에타"를 떠올리게 해서 아류처럼 보일 위험 |
| 상표·검색 | △ | 2026-10-26 웹 검색상 같은 이름의 국내외 댄스 서비스는 확인 안 됨 (유사 철자 Everdance 앱은 있음). 다만 "every + 일반명사"는 식별력이 약해 상표 등록에 불리할 수 있음 → KIPRIS 확인 필요 |
| 곡 중심·요청 정체성 | × | 우리의 대전제(곡으로 찾기)와 무기(요청)가 이름에 전혀 없음 |

### 확장성과 훅을 둘 다 잡는 방법: 브랜드 / 기능 이름 분리
- **브랜드(앱 이름)** = 확장성 담당. 오래 써도 안 막히는 이름
- **기능·캠페인 이름** = 훅 담당. 귀엽고 키치하게. 바꿔도 부담 없음
- 예: 배달의민족(브랜드) + B마트·배민1(기능) / 토스(브랜드) + 행운퀴즈·만보기(기능)

| 브랜드 | 요청 기능 이름 | 그 외 |
|---|---|---|
| 에브리댄스 (에댄) | "추가요!" 버튼 | 이번 주 인기곡 섹션 "츔픽" |
| 츔 | "추가요!" | — (츔 자체가 키치해서 분리 부담 적음) |

### 확장성 있는 키치 후보 재분류
3차 후보 중 장르·지역 제약 없이 확장 가능한 것: **츔, 추추, 둠칫, 춤바람, 뚝딱** — 전부 "춤"만 담고 K-pop·원데이에 묶이지 않음.
"추가요"는 '가요'가 K-pop에 묶이므로 브랜드보다 **요청 기능 이름**에 더 적합.

## 9. 추가 후보 검토 — 에브리코레오(에코), 올 더 비트(올빗) (2026-10-26)

### 에브리코레오 (EveryChoreo, 에코)
- 철자: Chreo가 아니라 **Choreo**
- 2026-10-26 웹 검색상 같은 이름의 서비스는 확인 안 됨
- **문제 1 — 줄임말 "에코"의 오염이 심함.** 친환경(eco), 메아리(echo), 에코백, Amazon Echo, 에코프로(주식)… "에코에서 봤어"라고 들은 사람이 검색하면 우리를 못 찾는다. 줄임말로 기억되는 전략에 정면으로 불리
- **문제 2 — "코레오"는 국내 댄스판에서 장르 이름.** 코레오 클래스 = 강사가 직접 짠 안무를 배우는 수업 (방송댄스·커버댄스보다 고가, 숙련자 대상). 우리 대전제는 **기존 곡 안무를 배우는 커버 원데이**라서, 이름이 타깃과 다른 장르를 가리키게 됨
- 장점: 댄서 커뮤니티에서는 "아는 사람이 만든" 느낌. "에코 = 메아리 = 요청이 퍼진다"는 스토리는 가능

### 올 더 비트 (All the Beat, 올빗)
- 2026-10-26 웹 검색상 "올빗 / All the Beat" 서비스는 확인 안 됨. "비트(Beat)" 단독 이름은 커피(b;eat)·음악 스트리밍·택시 앱 등으로 이미 많음 → "올빗"으로 묶어 써야 구분됨
- **장점**
  - **비트 = 음악 = 곡.** 대전제(곡 중심)를 담은 유일한 확장형 이름
  - 장르·지역 제약 없음 (힙합 비트, K-pop 비트, 해외 모두 가능)
  - "올빗"은 2음절, 올리브영→올영 같은 "올-" 줄임 패턴이라 익숙함
  - 오염이 적음
- **주의**
  - 영어 문법상 자연스러운 건 "All the Beats" (복수). 브랜드로는 단수도 괜찮지만 원어민에게 어색할 수 있음 → 영문 표기는 **ALLBEAT / allbit** 같은 조어로 정리하는 방법도 있음
  - "올빗"을 처음 보면 머리 빗는 "빗"으로 읽힐 수 있음 → 로고·첫 노출에서 "All the Beat"를 함께 보여줘 학습시키기
  - 동사화는 약함 ("올빗하자"는 어색). 대신 "올빗에서 찾아봐", "올빗에 요청해"는 자연스러움
