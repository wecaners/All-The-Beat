# 00. 유사·경쟁 서비스 리서치

- 작성일: 2026-10-26
- 목적: K-pop 댄스 원데이 클래스 탐색·예약·요청 서비스(가칭)의 경쟁 환경 파악
- 방법: 웹 검색 기반 1차 조사. 사용자 인터뷰·앱 직접 사용은 아직 안 함 (후속 과제)

## 1. 한 줄 결론

"곡/아티스트 단위로 오프라인 K-pop 댄스 원데이 클래스를 찾고, 열어달라고 요청하는" 서비스는 **국내외에서 확인되지 않았다.**
경쟁은 (a) 범용 취미 플랫폼, (b) 대형 스튜디오 자체 앱, (c) 댄스 디렉터리형 소규모 서비스, (d) 인스타/네이버 예약이라는 "비(非)플랫폼" 네 갈래다.
가장 강한 경쟁자는 (d)다.

## 2. 경쟁 지도

| 분류 | 서비스 | 하는 일 | 우리와의 차이 / 빈틈 |
|---|---|---|---|
| 범용 취미 플랫폼 | 탈잉, 숨고, 솜씨당, 클래스101, 크몽 | 전 분야 클래스·튜터 매칭. 댄스는 수많은 카테고리 중 하나 | 곡/아티스트 검색 없음. 강사 프로필·1:1 위주. 원데이 그룹 클래스의 "이번 주 일정" 탐색에 약함 |
| 대형 스튜디오 자체 앱 | 1MILLION, 호댄스(부산), 프로젝트리(홍대), 이댄스 등 | 자사 수업 스케줄·티켓·QR 입장 | 자기 스튜디오만. 개인 강사 수업은 못 담음. 우리는 **개인 강사**가 타깃이라 직접 경쟁 아님 |
| 댄스 디렉터리형 | 프리즈(FREEZE), DANFLIX | 학원·레슨·행사를 모아 보여주는 디렉터리 | 프리즈는 **학원 단위** 디렉터리로 보임. DANFLIX는 vercel.app 도메인이라 사이드 프로젝트/데모 가능성 높음. 둘 다 곡 기반 검색·요청 기능은 확인 안 됨 (직접 사용 확인 필요) |
| 관광객 대상 | Klook, 마이리얼트립, Airbnb 체험 | 외국인용 K-pop 댄스 체험 상품 | 다른 고객군. 다만 "외국인 수요"는 나중에 확장 옵션 |
| 연습/학습 앱 | STEPIN, SPARKY, JustMove, DNCR | AI 동작 채점, 온라인 튜토리얼 | 오프라인 예약 기능 없음. K-pop 안무 **수요가 충분히 크다**는 간접 증거 |
| 비플랫폼 (현재의 지배적 방식) | 인스타 스토리+DM, 네이버 예약, 카카오 오픈채팅, 계좌 입금 확인, 당근 소모임 | 강사가 알아서 모집·관리 | **진짜 경쟁자.** 공짜, 익숙함, 팔로워 기반. 우리가 이걸 대체하려 하면 진다. 보완·연결해야 함 |

## 3. 관찰된 현재 예약 방식 (검색으로 확인된 것)

- 자체 예약 페이지 + 선착순
- 지정 계좌 입금 확인 후 신청 완료 (이댄스학원)
- 앱 쿠폰제 (호댄스)
- 문자/카톡 상담 신청 (SM Universe)
- 당근 소모임 + 인스타 소통, 클래스당 10명 선착순
- (사용자 관찰) 인스타 스토리 → DM → 네이버 예약 링크

→ 방식이 강사마다 제각각이라 수강생은 **"어디서 뭘 하는지 한눈에 볼 곳"이 없다.** 이 분산 자체가 우리 기회.

## 4. 가격 참고

- 원데이 클래스 60분 평균 약 4만 원 (크몽 기준, 1만~18만 원 분포)
- 학원 체험 1회 3만 원 수준
- 1MILLION 1회 약 28 USD, 5회 125 USD
- 숨고 개인 강사 1시간 3.5만~5만 원

## 5. 시사점

1. **빈틈은 실재한다.** 곡 중심 탐색 + 요청(수요 집계) 조합은 아무도 안 하고 있다.
2. **강사는 인스타를 안 떠난다.** 1차 MVP는 인스타·네이버 예약을 대체하지 말고 **그 위에 얹는 레이어**여야 한다. (등록 1분, 예약은 강사 기존 링크로 연결)
3. **공급(강사 등록)이 병목이다.** 초기엔 우리가 직접 인스타에서 공개된 클래스 정보를 수집·등록하는 "콘시어지 MVP"가 현실적. 단, 강사 동의·저작권(사진) 이슈 확인 필요.
4. **DANFLIX·프리즈는 직접 써보고 판단할 것.** 비슷한 시도가 왜 안 컸는지(혹은 컸는지)가 우리 리스크 판단에 중요.
5. **사용자 인터뷰 필수.** 우리 둘 다 수강생이 아님. 수강생 5명 + 개인 강사 2~3명 인터뷰 전에는 기능 우선순위를 확정하지 않는다.

## 6. 열린 질문 (다음 단계에서 답할 것)

- 수강생이 클래스를 고를 때 1순위 기준은? (곡 / 강사 / 위치 / 시간 / 가격)
- 강사는 지금 DM 관리에 실제로 얼마나 시간을 쓰나? 불편하긴 한가?
- "요청 게시판"에 올라온 수요를 강사가 실제로 반영할 유인이 있나?
- 네이버 예약을 쓰는 강사 비율 vs DM/입금 확인만 쓰는 비율
