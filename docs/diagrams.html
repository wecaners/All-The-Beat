4. 강사 신청 → 인증 → 승인 (강사·운영자)

05-유저플로우.md

sequenceDiagram
    autonumber
    actor T as 강사
    participant A as 올빗
    actor O as 운영자
    participant IG as 인스타그램 DM

    T->>A: 마이 → 강사 신청 T-01<br/>활동명 · 인스타 핸들 · 권역
    A->>A: 같은 핸들의 대리 프로필 있나?
    alt 대리 프로필 있음
        A-->>T: "이미 등록된 클래스가 있어요" → 플로우 9 클레임
    else 없음
        A-->>T: 상태 "승인 대기"
        A->>O: 승인 대기 목록 A-02에 표시
        O->>A: 인증 코드 발급
        O->>IG: 강사 인스타로 코드 DM 발송
        IG-->>T: 6자리 코드 수신
        T->>A: 마이에서 코드 입력
        A-->>O: "인증됨" 표시
        alt 승인
            O->>A: [승인]
            A-->>T: 강사 권한 부여 · 클래스 등록 가능
        else 반려
            O->>A: [반려] + 사유
            A-->>T: 사유 표시 · 재신청 가능
        end
    end
